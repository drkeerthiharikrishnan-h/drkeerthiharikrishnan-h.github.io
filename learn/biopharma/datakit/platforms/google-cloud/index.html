Platform reference · Google Cloud

Google Cloud

Google Cloud offers BigQuery for SQL over large tables, Cloud Storage for objects, and the Cloud Healthcare API for FHIR, DICOM and HL7v2 data; it also hosts public datasets that anyone with a project can query. This page covers those services, two openly documented life-science datasets reachable on BigQuery (Open Targets, the MIMIC-IV demo), and the open-source genomics and health-data tools Google and ISB-CGC publish on GitHub.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

BigQuery

Google Cloud · Vendor-published · documented, not executed here

A fully managed, serverless data platform for managing and analysing data with SQL and Python without managing infrastructure. Key uses the page lists include machine learning and predictive analytics on the data, business intelligence and ad hoc analysis, geospatial analysis, data governance, and generative AI features in data workflows.

Managed cloud service that needs an account with the vendor; documented, not executed here. Queries run in a Google Cloud project.

Life-science example: Open Targets documents its Platform data as a Google Cloud public dataset in the BigQuery project open-targets-prod, with sample SQL queries.

Source: BigQuery overview, Google Cloud documentation. Opened 12 Nov 2026. Also opened: PyPI record of the google-cloud-bigquery Python client.

Cloud Storage

Google Cloud · Vendor-published · documented, not executed here

A managed storage service for unstructured data, held as objects in containers called buckets that belong to a project. Buckets can be shared with chosen principals or made accessible to everyone on the public internet. The page lists storing datasets for analytics and machine learning and archiving backups among its uses.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: Cloud Storage overview, Google Cloud documentation. Opened 12 Nov 2026. Also opened: PyPI record of the google-cloud-storage Python client.

BigQuery public datasets (Google Cloud Public Dataset Program)

Google Cloud · Vendor-published · documented, not executed here

Datasets stored in BigQuery and made available to the general public through the Google Cloud Public Dataset Program. Google pays for storage; users pay only for their queries, with the first 1 TB per month free subject to query pricing. Tables are queried by fully qualified name in the bigquery-public-data project. The page says there is no service-level agreement for the programme and that public datasets are not accessible by default from inside a VPC Service Controls perimeter.

Managed cloud service that needs an account with the vendor; documented, not executed here. No life-science table in bigquery-public-data was opened.

Source: BigQuery public datasets, Google Cloud documentation. Opened 12 Nov 2026.

Open Targets Platform on Google BigQuery

Open Targets · Publisher-published · documented, not executed here

Open Targets documents that its Platform data is also a Google Cloud public dataset in its BigQuery instance open-targets-prod, for complex queries and workflows on Google Cloud. Users pay only for their queries, with the first 1 TB per month free. Access is through the Cloud Console, the bq command-line tool or client libraries, and the page gives a sample query on the association_overall_direct dataset.

Queries need a Google Cloud project; documented, not executed here. The same releases are also listed as files on the Registry of Open Data on AWS.

Source: Google BigQuery, Open Targets Platform documentation. Opened 12 Nov 2026.

MIMIC-IV Clinical Database Demo v2.2

PhysioNet (MIT Laboratory for Computational Physiology) · Publisher-published · open to run here

An openly available demo of MIMIC-IV with a subset of 100 patients from the deidentified Beth Israel Deaconess Medical Center records; it has similar content to MIMIC-IV but excludes free-text clinical notes. Files are CSV, and the page says the dataset is also made available on Google BigQuery. Access policy: anyone can access the files if they keep to the licence, the Open Data Commons Open Database License v1.0.

Open access CSV files per the page; nothing was downloaded, so this is documented, not executed here.

Source: MIMIC-IV Clinical Database Demo v2.2, PhysioNet. Opened 12 Nov 2026.

Cloud Healthcare examples repository (GoogleCloudPlatform/healthcare)

Google Cloud · Vendor-published · documented, not executed here

Google repository of design patterns, examples and utilities for healthcare on Google Cloud, organised in subfolders. GitHub shows it as archived by the owner on 5 March 2026 and read-only, so it is a historical reference.

Archived example code for Google Cloud; documented, not executed here.

Source: GoogleCloudPlatform/healthcare, GitHub repository GoogleCloudPlatform/healthcare. Opened 12 Nov 2026. Also opened: Cloud Healthcare API documentation: a managed service for storing and accessing healthcare data in Google Cloud, with guides for FHIR stores and resources, DICOM stores and DICOMweb, and HL7v2 messages.

Healthcare data harmonization (Whistle)

Google Cloud · Vendor-published · documented, not executed here

Whistle is a mapping language and engine for converting complex, nested data from one schema to another, driven by a configuration file. The README calls it a terse syntax for transforming healthcare data that also applies to other domains; the engine can be extended with plugins. Building it needs Git, JDK 11 and Gradle 7.

Apache-2.0 source built with Gradle; a local build was not tried, so this is documented, not executed here.

Source: GoogleCloudPlatform/healthcare-data-harmonization, GitHub repository GoogleCloudPlatform/healthcare-data-harmonization. Opened 12 Nov 2026.

GCP Variant Transforms

Google Cloud · Vendor-published · documented, not executed here

A tool for transforming and processing VCF files at scale with Apache Beam on Dataflow, which can load VCF files directly into BigQuery. It also has a preprocessing step that validates VCF files so inconsistencies can be found.

Runs on Google Cloud Dataflow; documented, not executed here.

Source: googlegenomics/gcp-variant-transforms, GitHub repository googlegenomics/gcp-variant-transforms. Opened 12 Nov 2026.

DeepVariant

Google · Vendor-published · open to run here

A deep learning-based variant caller: it takes aligned reads in BAM or CRAM format, makes pileup image tensors, classifies each with a convolutional neural network and writes a standard VCF or gVCF. It supports germline variant calling in diploid organisms, with case studies for several sequencing platforms, and has been adapted for somatic calling.

Open source (BSD-3-Clause per the repository page); the README recommends the Docker image and also offers binaries. It needs Docker and reference data; not run here, so this is documented, not executed here.

Source: google/deepvariant, GitHub repository google/deepvariant. Opened 12 Nov 2026.

Pharma and life sciences demo applications (GoogleCloudPlatform/LifeSciences)

Google Cloud · Vendor-published · documented, not executed here

A collection of demo applications showing Google Cloud services used for pharma and life sciences, each with its own README. The list on the page names an agentic pre-clinical R&D system (Open Agentic Science Engine), an agentic interface for protein structure prediction (FoldRun), custom Gemini Enterprise agents for pharma workflows, and Sentinel, which evaluates whether documents and videos comply with medical regulations.

Deploys to Google Cloud; documented, not executed here.

Source: GoogleCloudPlatform/LifeSciences, GitHub repository GoogleCloudPlatform/LifeSciences. Opened 12 Nov 2026.

ISB-CGC community notebooks

ISB-CGC · Publisher-published · documented, not executed here

R and Python notebooks from ISB-CGC that use Google Cloud tools such as BigQuery for common data-analysis tasks, each narrow in scope and answering a single question. The README says notebooks open in Colab and that many need a Google Cloud project, for example to use BigQuery.

Needs a Google Cloud project for BigQuery; documented, not executed here.

Source: isb-cgc/Community-Notebooks, GitHub repository isb-cgc/Community-Notebooks. Opened 12 Nov 2026.
