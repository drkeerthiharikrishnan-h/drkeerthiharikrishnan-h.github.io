Open source data platforms and workflow tools

Open-source building blocks that sit underneath the vendor clouds on the other platform pages: a local SQL engine, open table and file formats, transformation and orchestration tools, bioinformatics workflow engines and pipelines, and the OMOP common data model. Each entry is described from its own repository or project page as opened on 12 Nov 2026, with the licence that page shows.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

DuckDB

DuckDB Foundation · Publisher-published · open to run here

Analytical SQL database that runs inside the calling program, with no separate server. It reads and writes CSV, Parquet, JSON and Excel files from local disk or remote endpoints, and has clients for Python, R, Java and other languages.

MIT licence per the repository; the duckdb package is on PyPI (version 2.0.0, Python >=3.11 on the day opened). Not installed or run here.

Source: GitHub - duckdb/duckdb: DuckDB is a high-performance analytical database system, DuckDB (duckdb/duckdb GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata: summary "DuckDB in-process database", MIT licence classifier, PyPI metadata for the dbt adapter that targets DuckDB (see oss-dbt).

Apache Spark

Apache Software Foundation · Publisher-published · open to run here

Engine for large-scale data processing. The README lists APIs in Scala, Java, Python and R (the R API marked deprecated) and higher-level tools: Spark SQL and DataFrames, pandas API on Spark, MLlib, GraphX and Structured Streaming.

Apache-2.0 per the repository; pyspark is on PyPI (version 4.3.0, licence Apache-2.0, Python >=3.11 on the day opened). Not installed or run here.

Source: GitHub - apache/spark: Apache Spark - A unified analytics engine for large-scale data processing, Apache Software Foundation (apache/spark GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata: summary "Apache Spark Python API".

Delta Lake

Delta Lake project (delta-io) · Publisher-published · open to run here

Open-source storage framework for a lakehouse architecture that works with compute engines including Spark, PrestoDB, Flink, Trino and Hive, with APIs for Scala, Java, Rust, Ruby and Python. delta-rs is a native Rust library for Delta Lake with Python bindings.

Apache-2.0 per both repositories; the deltalake Python package (built on delta-rs) is on PyPI with an Apache licence classifier. Not installed or run here.

Source: GitHub - delta-io/delta: An open-source storage framework that enables building a Lakehouse architecture with compute engines including Spark, PrestoDB, Flink, Trino, and Hive and APIs, Delta Lake project (delta-io/delta GitHub repository). Opened 12 Nov 2026. Also opened: delta-rs: native Rust library with Python bindings; installs with pip install deltalake, PyPI metadata for deltalake 1.6.6, Python >=3.10.

Apache Parquet and Apache Arrow

Apache Software Foundation · Publisher-published · open to run here

Parquet is an open-source, column-oriented data file format for storage and retrieval; the repository holds its specification and Thrift metadata definitions. Arrow is a columnar in-memory format and multi-language toolbox for data interchange and in-memory analytics, including an IPC format, ADBC and Flight RPC.

Apache-2.0 per both repositories. The format is read and written by the DuckDB, Spark and Delta Lake tools on this page. Not installed or run here.

Source: GitHub - apache/parquet-format: Apache Parquet Format, Apache Software Foundation (apache/parquet-format GitHub repository). Opened 12 Nov 2026. Also opened: Apache Arrow repository; Apache-2.0.

Apache Iceberg and Apache Polaris

Apache Software Foundation · Publisher-published · documented, not executed here

Iceberg is a table format for very large analytic tables that lets engines such as Spark, Trino, Flink, Presto, Hive and Impala work with the same tables at the same time; the core Java library in the repository is the reference implementation. Polaris is an open-source catalogue for Iceberg that implements the Iceberg REST API.

Apache-2.0 per both repositories. The Java library builds with Gradle and Polaris runs as a catalogue service; no laptop route was checked, so this entry is documented, not executed here.

Source: GitHub - apache/iceberg: Apache Iceberg, Apache Software Foundation (apache/iceberg GitHub repository). Opened 12 Nov 2026. Also opened: Apache Polaris repository; Apache-2.0; quickstart sets up a local or cloud instance.

dbt (dbt-core) with the dbt-duckdb adapter

dbt Labs · Vendor-published · open to run here

Tool for transforming data with software-engineering practice. The repository now warns that its main branch holds dbt v2.0, a ground-up rewrite in Rust under Apache 2.0, and that v1 (the Python implementation) moved to the 1.latest branch. dbt-duckdb is a separate adapter that points dbt at DuckDB.

dbt-core on PyPI is version 1.12.7 with licence expression Apache-2.0 (Python >=3.10); dbt-duckdb 1.11.1 has an Apache licence classifier. The repository README also names a "dbt" distribution under a separate dbt product license. Not installed or run here.

Source: GitHub - dbt-labs/dbt: dbt enables data analysts and engineers to transform their data using the same practices that software engineers use to build applications., dbt Labs (dbt-labs/dbt GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata for dbt-core, PyPI metadata for the dbt-duckdb adapter.

Apache Airflow

Apache Software Foundation · Publisher-published · open to run here

Platform to author, schedule and monitor workflows defined as code. Workflows are Dags of tasks; a scheduler runs the tasks on workers following their dependencies, and a web interface shows pipeline progress.

Apache-2.0 per the repository; apache-airflow is on PyPI (version 3.4.0, Python >=3.11 and not 3.15, on the day opened). It runs a scheduler and workers, so it is heavier than the other local tools. Not installed or run here.

Source: GitHub - apache/airflow: Apache Airflow - A platform to programmatically author, schedule, and monitor workflows, Apache Software Foundation (apache/airflow GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata: summary "Programmatically author, schedule and monitor data pipelines".

Nextflow

Nextflow project (nextflow-io) · Publisher-published · open to run here

Workflow system for scalable, portable and reproducible pipelines, based on the dataflow programming model. The README says it can deploy workflows on a local machine, HPC schedulers, AWS Batch, Azure Batch, Google Cloud Batch and Kubernetes, with software from Conda, Spack, Docker, Podman or Singularity.

Apache-2.0 per the repository; the README installs a single executable with a curl command or from Bioconda. Not installed or run here.

Source: GitHub - nextflow-io/nextflow: A workflow language for data-driven computational pipelines, Nextflow project (nextflow-io/nextflow GitHub repository). Opened 12 Nov 2026.

nf-core/rnaseq and nf-core/sarek

nf-core community · Publisher-published · open to run here

Community Nextflow pipelines. nf-core/rnaseq analyses RNA sequencing data from organisms with a reference genome and annotation, from FASTQ or BAM input to a gene expression matrix and QC report. nf-core/sarek detects germline or somatic variants from whole-genome or targeted sequencing and can handle tumour/normal pairs.

MIT per both repositories. The pipelines run under Nextflow with Docker, Singularity or similar containers. Not installed or run here.

Source: GitHub - nf-core/rnaseq: RNA sequencing analysis pipeline using STAR, RSEM, HISAT2 or Salmon with gene/isoform counts and extensive quality control., nf-core community (nf-core/rnaseq GitHub repository). Opened 12 Nov 2026. Also opened: nf-core/sarek repository; MIT.

Cromwell

Broad Institute · Publisher-published · open to run here

Open-source workflow management system for bioinformatics that runs WDL workflows. The README says many users run their WDL workflows in Terra.

The README states licensing is BSD 3-Clause (the repository sidebar also lists an Apache-2.0 licence file). Not installed or run here.

Source: GitHub - broadinstitute/cromwell: Scientific workflow engine designed for simplicity & scalability. Trivially transition between one off use cases to massive scale production environments, Broad Institute (broadinstitute/cromwell GitHub repository). Opened 12 Nov 2026.

OMOP Common Data Model

OHDSI · Publisher-published · open to run here

Open community data standard for the structure and content of observational health data. The site describes each released version of the model, its table and field conventions, and the OHDSI standardised vocabularies (downloadable from Athena). The GitHub repository generates the SQL DDLs; Eunomia serves sample OMOP CDM datasets for testing and demonstration.

The CommonDataModel R package builds DDLs locally; Eunomia (licensed under Apache License 2.0 per its README) runs in an R session on SQLite with no database server, default dataset GiBleed in CDM v5.5 format. Not installed or run here.

Source: OMOP Common Data Model – OMOP Common Data Model, OHDSI. Opened 12 Nov 2026. Also opened: Definition and DDLs for the OMOP CDM; the R package can build or execute the DDL for supported dialects, Eunomia: sample OMOP CDM datasets for testing and demonstration; default dataset GiBleed.
