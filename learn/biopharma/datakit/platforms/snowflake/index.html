Platform reference · Snowflake

Snowflake

Snowflake is a cloud data platform sold as a self-managed service: storage, compute and coordinating services run on the public cloud and nothing is installed locally. This page covers the architecture, Snowpark for code that runs next to the data, Apache Iceberg tables, Cortex Search for retrieval over text, Streamlit apps, the Marketplace for shared data, and two public healthcare and life-sciences repositories from Snowflake Labs.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

Snowflake platform (key concepts and architecture)

Snowflake · Vendor-published · documented, not executed here

Overview of how Snowflake is built. It is a self-managed service on public cloud infrastructure: there is no hardware or software for the customer to install, and the page says Snowflake cannot be installed and run locally or on private cloud. The architecture has three key layers (database storage, compute, cloud services) and stores structured, semi-structured (for example JSON or XML) and unstructured data.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: Snowflake key concepts and architecture, Snowflake documentation. Opened 12 Nov 2026. Also opened: PyPI record of the Snowflake Connector for Python, a Python DB API 2.0 driver (version 5.2.0, Apache-2.0, Python >=3.11 on the day opened).

Snowpark API

Snowflake · Vendor-published · documented, not executed here

Libraries for querying and processing data inside Snowflake, so applications work on the data without moving it to the machine where the code runs. The page lists Snowpark libraries for three languages: Java, Python and Scala.

The Python client installs from PyPI but works against a Snowflake account; documented, not executed here.

Source: Snowpark API, Snowflake documentation. Opened 12 Nov 2026. Also opened: Repository of the Snowpark Python and Snowpark pandas APIs (Apache-2.0), PyPI record of snowflake-snowpark-python (version 1.57.0, Apache License 2.0, Python >=3.10,<3.15 on the day opened).

Apache Iceberg tables

Snowflake · Vendor-published · documented, not executed here

Snowflake tables in the open Apache Iceberg table format, which gives ACID transactions, schema evolution, hidden partitioning and table snapshots over Parquet data files. Data and metadata files sit in cloud storage, either managed by Snowflake or in an external volume the customer manages on Amazon S3, Google Cloud Storage or Azure Storage. The page says these tables suit existing data lakes that are not stored in Snowflake.

Managed cloud service that needs an account with the vendor; documented, not executed here. The open Iceberg format and the Polaris catalog are open-source Apache projects; neither was run here.

Source: Apache Iceberg tables, Snowflake documentation. Opened 12 Nov 2026. Also opened: Apache Iceberg repository: a table format for large analytic tables, developed at the Apache Software Foundation (Apache-2.0), Apache Polaris repository: an open-source catalog for Apache Iceberg that implements the Iceberg REST API (Apache-2.0).

Cortex Search

Snowflake · Vendor-published · documented, not executed here

A hybrid (vector and keyword) search engine over text data held in Snowflake, with embedding, infrastructure and index refresh handled by the service. The page names two primary uses, retrieval augmented generation (RAG) for chat applications and enterprise search, and also its use as the retrieval layer for Cortex Agents.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Life-science example: The Snowflake HCLS solution catalogue lists a Clinical Quality and Patient Safety Agent whose features include Cortex Search over PubMed.

Source: Cortex Search, Snowflake documentation. Opened 12 Nov 2026.

Streamlit in Snowflake

Snowflake · Vendor-published · documented, not executed here

Hosting for Streamlit apps inside Snowflake, so an app reads and processes data in Snowflake without moving data or code to an outside system. Snowflake manages the compute and storage, keeps the source code in an object governed by role-based access control, and offers a warehouse or container runtime. Streamlit itself is an open-source Python library.

Managed cloud service that needs an account with the vendor; documented, not executed here. Open-source Streamlit runs locally; that was not tried here.

Source: About Streamlit in Snowflake, Snowflake documentation. Opened 12 Nov 2026.

Snowflake Marketplace

Snowflake · Vendor-published · documented, not executed here

A place to explore, access and provide data listings. Providers share curated data with many consumers through one listing, can publish free-to-use datasets, and can charge through paid listings; consumers discover third-party data and services. The page says it is available to Snowflake accounts on Amazon Web Services, Google Cloud and Microsoft Azure, except Microsoft Azure Government.

Managed cloud service that needs an account with the vendor; documented, not executed here. No life-science listing was opened.

Source: About Snowflake Marketplace, Snowflake documentation. Opened 12 Nov 2026.

Healthcare and life sciences solution accelerators (Snowflake-Labs/sf-hcls-solutions)

Snowflake · Vendor-published · documented, not executed here

A repository of end-to-end healthcare and life-sciences accelerators built on Snowflake. Its catalogue lists three solutions: a Clinical Quality and Patient Safety Agent (Cortex Search over PubMed among its features), a Medical Device Streaming Platform and a Scientific Workbench for Life Sciences R&D. It needs Python 3.12+ and uv. The README says the application is not part of the Snowflake Service.

Apache-2.0 code that installs into a Snowflake account; documented, not executed here.

Source: Snowflake-Labs/sf-hcls-solutions, GitHub repository Snowflake-Labs/sf-hcls-solutions. Opened 12 Nov 2026.

Guide: LLM-assisted medical coding extraction

Snowflake · Vendor-published · documented, not executed here

A QuickStart guide repository on clinical coding: turning free-text medical records into structured codes in a classification system such as ICD-10. It uses large language models in Snowflake, with a fine-tuning step, to extract and analyse medical codes from patient reports. Setup and steps are in the linked QuickStart guide.

Needs a Snowflake account; documented, not executed here.

Source: Snowflake-Labs/sfguide-llm-assisted-medical-coding-extraction-for-healthcare-in-snowflake, GitHub repository Snowflake-Labs/sfguide-llm-assisted-medical-coding-extraction-for-healthcare-in-snowflake. Opened 12 Nov 2026.
