Platform reference · Visualisation tools

Visualisation tools for omics and clinical data

Tools that put data in front of people: cancer-genomics and single-cell explorers, a genome browser component, general app frameworks (Shiny, Streamlit) and teal, a Shiny-based framework for clinical trial data, and the Tableau products. Open-source entries name the licence their page shows; Tableau products are documented only. Each entry is described from the page opened on 12 Nov 2026.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

cBioPortal for Cancer Genomics

cBioPortal project · Publisher-published · documented, not executed here

Open-source portal for visualising, analysing and downloading large-scale cancer genomics datasets. The README says the master branch is now the pre-release branch for v7, which introduces a ClickHouse-only database not compatible with the earlier MySQL mode or existing study importer tools; v6 gets security fixes only. The public datahub repository holds validated study staging files, managed with Git LFS.

Apache-2.0 per the repository, but the portal is a server deployment, so it is documented, not executed here. From a laptop a lab can read the public instance API (the info endpoint reported portalVersion v7.2.3 when opened today) and download datahub study files, which the datahub states are available under the ODC Open Database License (ODbL).

Source: GitHub - cBioPortal/cbioportal: cBioPortal for Cancer Genomics, cBioPortal project (cBioPortal/cbioportal GitHub repository). Opened 12 Nov 2026. Also opened: Public datahub: validated staging files per study; data under ODbL; zipped studies downloadable from the cbioportal.org datasets page, Public instance info endpoint (JSON).

CELLxGENE Explorer (repository name: CZ CELLxGENE Annotate)

Chan Zuckerberg Initiative · Publisher-published · open to run here

Interactive explorer for single-cell transcriptomics data; the repository now names the tool CZ CELLxGENE Annotate. The README quick start installs it with pip and launches it on an example AnnData file (pbmc3k.h5ad). The companion CELLxGENE Discover portal publishes interoperable single-cell datasets that can be downloaded or opened in the explorer.

MIT per the repository and PyPI (cellxgene 1.3.0, Python >=3.10 on the day opened); runs locally. Not installed or run here.

Source: GitHub - chanzuckerberg/cellxgene: An interactive explorer for single-cell transcriptomics data, Chan Zuckerberg Initiative (chanzuckerberg/cellxgene GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata: "Web application for exploration of large scale scRNA-seq datasets", CZ CELLxGENE Discover portal repository; MIT.

CZ CELLxGENE Discover Census

Chan Zuckerberg Initiative · Publisher-published · open to run here

Free-to-use service (API plus data) for querying the CZ CELLxGENE Discover single-cell corpus directly into Python or R.

Repository contents are under the MIT license and data in the Census under the CC-BY license, per the README. The cellxgene-census package on PyPI is version 1.18.0 (Development Status 4 - Beta). The client installs locally; the data is served by the hosted service. Not installed or run here.

Source: GitHub - chanzuckerberg/cellxgene-census: CZ CELLxGENE Discover Census, Chan Zuckerberg Initiative (chanzuckerberg/cellxgene-census GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata for cellxgene-census.

Tableau developer tooling: TabPy, Tableau Server Client, Hyper API

Tableau (Salesforce) · Vendor-published · documented, not executed here

Open-source libraries around the proprietary Tableau products. TabPy (Tableau Python Server) is an Analytics Extension that lets Tableau table calculations run Python scripts and saved functions; its README warns that it is configured without authentication by default and advises enabling it. Tableau Server Client is a Python library for the Tableau Server REST API (publishing workbooks and data sources, managing users and groups). The Hyper API for Python is on PyPI.

TabPy and Tableau Server Client show an MIT licence; tableauhyperapi on PyPI shows Apache-2.0. They serve proprietary Tableau products, so this entry is documented, not executed here.

Source: GitHub - tableau/TabPy: Execute Python code on the fly and display results in Tableau visualizations:, Tableau (tableau/TabPy GitHub repository). Opened 12 Nov 2026. Also opened: Tableau Server Client (Python); the README says support for Python 3.9 was dropped as of October 2026, PyPI metadata: "Hyper API for Python", licence Apache-2.0.

Tableau Public

Tableau (Salesforce) · Vendor-published · documented, not executed here

Free hosted platform from Tableau for exploring, creating and publicly sharing data visualisations online. The page calls it a platform for public (not private) data: published visualisations are available for anyone to see online, and data refresh is limited.

Proprietary hosted service used through a free profile; documented, not executed here.

Source: Tableau Public | Tableau, Tableau. Opened 12 Nov 2026.

Shiny (R) and Shiny for Python

Posit (rstudio and posit-dev on GitHub) · Vendor-published · open to run here

Framework for interactive web applications written in R (shiny) or Python (Shiny for Python). Its reactive programming model updates outputs automatically when inputs change, and it ships prebuilt widgets such as plots, tables, sliders and date pickers.

The README states the shiny package as a whole is licensed under the MIT License; CRAN lists shiny 1.14.0 (published 2026-06-21, licence MIT + file LICENSE). Shiny for Python is MIT; its README installs it with uv pip install shiny. Not installed or run here.

Life-science example: R Consortium Pilot 2 tested whether a Shiny application could be bundled into a submission package and transferred to FDA reviewers (see the submission tooling page).

Source: GitHub - rstudio/shiny: Easy interactive web applications with R, Posit (rstudio/shiny GitHub repository). Opened 12 Nov 2026. Also opened: CRAN package page for shiny, Shiny for Python repository; MIT.

Streamlit

Snowflake (Streamlit) · Vendor-published · open to run here

Open-source framework for data apps and dashboards; an app is written in Python, with no separate frontend. The README also names AI and chat apps over data, and points to a hosted Community Cloud for deploying and sharing apps.

Apache-2.0 per the repository and PyPI (streamlit 1.67.0, Python >=3.11 on the day opened; the PyPI author email field reads Snowflake Inc). Community Cloud is a hosted service outside this entry. Not installed or run here.

Source: GitHub - streamlit/streamlit: Streamlit — The agent-native framework for data apps and dashboards., Streamlit (streamlit/streamlit GitHub repository). Opened 14 Nov 2026. Also opened: PyPI metadata for streamlit.

teal

pharmaverse · Publisher-published · open to run here

Shiny-based framework for interactive exploratory analysis of clinical trial data. App developers specify the data (CDISC data, independent or related data frames, or MultiAssayExperiment objects) and teal modules, which are Shiny modules for analyses such as outlier exploration or line plots.

CRAN lists teal 1.2.1 (published 2026-07-29) under Apache License 2.0; it depends on R >= 4.1 and shiny. Not installed or run here.

Source: GitHub - pharmaverse/teal: Exploratory Web Apps for Analyzing Clinical Trial Data, pharmaverse (pharmaverse/teal GitHub repository). Opened 12 Nov 2026. Also opened: CRAN package page for teal.

igv.js

IGV team · Publisher-published · open to run here

Embeddable interactive genome visualisation component (JavaScript) from the Integrative Genomics Viewer team, with examples for alignments, interactions, copy number, multiple regions and MAF files. It is a single JavaScript file with no external dependencies.

MIT per the repository; pre-built files download from a CDN or npm. Not installed or run here.

Source: GitHub - igvteam/igv.js: Embeddable genomic visualization component based on the Integrative Genomics Viewer, IGV team (igvteam/igv.js GitHub repository). Opened 12 Nov 2026.
