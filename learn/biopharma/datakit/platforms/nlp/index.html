NLP tools for biomedical and clinical text

Libraries, pretrained language models, annotated corpora and an annotation service used to pull entities and relations out of literature and clinical text. Licences differ sharply between entries: some models carry an MIT tag, others show no licence at all, and one healthcare extension is proprietary. Each entry is described from the page opened on 12 Nov 2026.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

scispaCy

Allen Institute for AI · Publisher-published · open to run here

Custom spaCy pipes and models for scientific and biomedical documents: a tokenizer with extra rules, a part-of-speech tagger and syntactic parser trained on biomedical data, an entity span detector, and separate NER models for narrower tasks.

Apache-2.0 per the repository and the PyPI classifier. PyPI lists version 0.6.2 for Python >=3.9,<3.13 with the classifier "Development Status :: 3 - Alpha"; models install as separate packages. Not installed or run here.

Source: GitHub - allenai/scispacy: A full spaCy pipeline and models for scientific/biomedical documents., Allen Institute for AI (allenai/scispacy GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata for scispacy.

medspaCy

medspaCy project · Publisher-published · open to run here

Library of spaCy components for clinical text: preprocessing, clinical sentence splitting, concept extraction, the ConText algorithm for semantic modifiers and assertion attributes, and section detection. Each module can be used on its own inside a spaCy pipeline. The README says medspaCy is currently in beta.

MIT per the repository. Not installed or run here.

Source: GitHub - medspacy/medspacy: Library for clinical NLP with spaCy., medspaCy project (medspacy/medspacy GitHub repository). Opened 12 Nov 2026.

BiomedBERT (previously named PubMedBERT), abstracts + full text

Microsoft (model on Hugging Face) · Vendor-published · open to run here

Biomedical BERT model (fill-mask) pretrained from scratch on PubMed abstracts and PubMed Central full-text articles. The card records that the model was previously named "PubMedBERT (abstracts + full text)".

Card licence tag: mit. Model files download from Hugging Face; nothing was downloaded here. Not installed or run here.

Source: microsoft/BiomedNLP-BiomedBERT-base-uncased-abstract-fulltext · Hugging Face, Microsoft (Hugging Face model card). Opened 12 Nov 2026.

BioBERT v1.1

DMIS Lab (dmis-lab on Hugging Face) · Publisher-published · documented, not executed here

BioBERT v1.1 feature-extraction model. The repository page shows "No model card"; the collection that includes it describes BioBERT as a domain-specific adaptation of BERT pre-trained on biomedical corpora.

No model card and no licence tag on the page, so this kit does not treat it as open-source software: documented, not executed here. Check the licence at the original source before any lab uses it.

Source: dmis-lab/biobert-v1.1 · Hugging Face, DMIS Lab (Hugging Face model repository). Opened 12 Nov 2026.

SciBERT (scivocab, uncased)

Allen Institute for AI (model on Hugging Face) · Publisher-published · documented, not executed here

BERT model trained on the full text of scientific papers from Semantic Scholar (the card gives 1.14M papers, 3.1B tokens), with its own wordpiece vocabulary (scivocab); cased and uncased versions exist.

No licence tag on the card, so this kit does not treat it as open-source software: documented, not executed here. Check the licence before any lab uses it.

Source: allenai/scibert_scivocab_uncased · Hugging Face, Allen Institute for AI (Hugging Face model card). Opened 12 Nov 2026.

Bio+Clinical BERT

emilyalsentzer on Hugging Face · Publisher-published · open to run here

Bio+Clinical BERT: one of four models from the "Publicly Available Clinical BERT Embeddings" paper, initialised from BioBERT and trained on all notes in the MIMIC III NOTEEVENTS table (ICU electronic health records from Beth Israel Hospital, Boston).

Card licence tag: mit. Model files download from Hugging Face; nothing was downloaded here. Not installed or run here.

Source: emilyalsentzer/Bio_ClinicalBERT · Hugging Face, emilyalsentzer (Hugging Face model card). Opened 12 Nov 2026.

BioGPT

Microsoft (model on Hugging Face) · Vendor-published · open to run here

Domain-specific generative Transformer language model pre-trained on biomedical literature. The card contrasts it with BERT-style biomedical models such as BioBERT and PubMedBERT, which lack generation ability.

Card licence tag: mit. Model files download from Hugging Face; nothing was downloaded here. Not installed or run here.

Source: microsoft/biogpt · Hugging Face, Microsoft (Hugging Face model card). Opened 12 Nov 2026.

Biomedical NER corpora on Hugging Face: BC5CDR and NCBI disease

Hugging Face (hosting): bigbio and ncbi dataset repositories · Publisher-published · documented, not executed here

Two annotated biomedical NER corpora hosted as Hugging Face datasets. BC5CDR (BioCreative V Chemical Disease Relation) annotates all chemicals, diseases and their interactions in 1,500 PubMed articles. NCBI disease annotates 793 PubMed abstracts at the mention and concept level.

Datasets, not software, with card licence tags "other" (bc5cdr) and "unknown" (ncbi_disease): documented, not executed here. On the day opened the dataset viewer was unavailable for both (bc5cdr needs the bioc dependency; ncbi_disease uses a loading script). Check terms at the original source before a lab uses them.

Source: bigbio/bc5cdr · Datasets at Hugging Face, Hugging Face dataset repositories (bigbio, ncbi). Opened 12 Nov 2026. Also opened: Dataset card for NCBI Disease; licence tag unknown, Transformers library documentation index (the library these models load with).

PubTator3

NCBI / National Library of Medicine · Publisher-published · documented, not executed here

NCBI web service and FTP bulk files with automated annotations of genes and proteins, genetic variants, diseases, chemicals, species and cell lines, and the relations among them. The README gives the scope as PubMed (36 million abstracts) plus the PMC Open Access Subset and Author Manuscript Collection (6.3 million full-text articles), in BioC-XML and PubTator tab-separated formats, expected to be updated monthly.

A public NCBI service and data files rather than software installed here, so documented, not executed here. The README carries a US Government public-domain notice. The export API returned BioC JSON for PMID 1 when opened today, with one Disease annotation ("methanol poisoning", MESH:D011041).

Source: https://ftp.ncbi.nlm.nih.gov/pub/lu/PubTator3/README.txt, NCBI, National Library of Medicine. Opened 12 Nov 2026. Also opened: PubTator3 export API, BioC JSON for PMID 1.

Spark NLP (open-source library)

John Snow Labs · Vendor-published · open to run here

Natural language processing library built on Apache Spark, with pretrained pipelines and models and tasks such as tokenisation, named entity recognition, dependency parsing and text classification.

Apache-2.0 per the repository. The healthcare extension used in the Databricks example below is listed there under a proprietary licence and is not covered by this entry. Not installed or run here.

Life-science example: Databricks solution accelerator that uses Spark NLP models to extract adverse drug event and drug information from conversational text. Its licence table lists Spark NLP under Apache License 2.0 and "Spark NLP for Healthcare" under a proprietary John Snow Labs licence.

Source: GitHub - JohnSnowLabs/spark-nlp: State of the Art Natural Language Processing, John Snow Labs (JohnSnowLabs/spark-nlp GitHub repository). Opened 12 Nov 2026.
