Platform reference · Microsoft

Microsoft

Microsoft offers data lake storage (Azure Data Lake Storage, OneLake), the Fabric analytics platform with Power BI and Data Factory, and health services: Azure Health Data Services for FHIR and DICOM, healthcare data solutions in Fabric, and Text Analytics for health. This page lists them with their scope statements, the open-source FHIR tools Microsoft publishes, and the state of Azure Open Datasets, whose genomics datasets carry a deprecation notice. The healthcare data solutions delivery model is changing; dates are quoted only from the opened page.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

Azure Data Lake Storage

Microsoft · Vendor-published · documented, not executed here

A set of capabilities for big data analytics built on Azure Blob Storage. It adds file system semantics, file-level security and scale to Blob Storage, which brings tiered storage, high availability and disaster recovery. The page calls it the foundation for building enterprise data lakes on Azure.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: Azure Data Lake Storage overview, Microsoft Learn. Opened 12 Nov 2026. Also opened: PyPI record of the Azure File DataLake Storage client library for Python (version 12.26.1, MIT License, Python >=3.10 on the day opened).

OneLake (Microsoft Fabric)

Microsoft · Vendor-published · documented, not executed here

A unified data lake for a whole organisation that every Microsoft Fabric tenant includes automatically. It is built on Azure Data Lake Storage and stores tables in Delta Parquet or Iceberg format, which the page calls open standards any tool can read, so one copy of data serves several analytical engines.

Managed cloud service that needs an account with the vendor; documented, not executed here. Delta and Parquet files can be read and written with open-source tools; not tried here.

Source: OneLake, the unified data lake, Microsoft Learn. Opened 12 Nov 2026.

Microsoft Fabric

Microsoft · Vendor-published · documented, not executed here

An analytics platform for end-to-end data work: ingestion, transformation, real-time stream processing, analytics and reporting. Its experiences (Data Engineering, Data Factory, Data Science, Real-Time Intelligence, Data Warehouse, Databases, Power BI) share one compute and storage model. It is delivered as software as a service with OneLake as the central data lake, and shortcuts give access to external storage such as Azure Data Lake Storage, Amazon S3 and Google Cloud Storage without copying.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: What is Microsoft Fabric, Microsoft Learn. Opened 12 Nov 2026. Also opened: Microsoft Fabric samples repository (MIT) with hands-on examples and data for the Fabric Learn content.

Healthcare data solutions in Microsoft Fabric

Microsoft · Vendor-published · documented, not executed here

Healthcare capabilities in Fabric: healthcare data foundations built on FHIR with ready-to-run pipelines, OMOP transformations for standardised analytics, DICOM data transformation into OneLake, export of FHIR data from the Azure Health Data Services FHIR service, and CMS claims data transformations. An important notice on the page says Microsoft is changing the delivery model: a downloadable source code and documentation package is available from 3 August 2026, from 1 October 2026 only existing customers can deploy the current managed solution, and support for the managed solution ends on 31 December 2027.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: Healthcare data solutions in Microsoft Fabric, Microsoft Learn. Opened 12 Nov 2026.

Azure Health Data Services

Microsoft · Vendor-published · documented, not executed here

A cloud service to collect, store and analyse health data from different sources and formats. It supports healthcare standards such as FHIR and DICOM and converts data from legacy or proprietary device formats to FHIR.

Managed cloud service that needs an account with the vendor; documented, not executed here. Microsoft also publishes an open-source FHIR server, FHIR converter and anonymisation tools (MIT); none was deployed here.

Life-science example: Microsoft repository of open-source sample apps and code for getting started with Azure Health Data and AI services.

Source: What is Azure Health Data Services?, Microsoft Learn. Opened 12 Nov 2026. Also opened: FHIR Server for Azure: an open-source .NET Core implementation of the HL7 FHIR specification designed for the Microsoft cloud (MIT), FHIR Converter: open-source utility (MIT) that converts health data between legacy formats and FHIR, including HL7v2, C-CDA and JSON to FHIR and FHIR STU3 to R4, using Liquid templates and .NET, Tools for Health Data Anonymization: scripts and command-line tools (MIT) for anonymising data in FHIR format; the README says the project does not access the user's data.

Text Analytics for health (Azure Language)

Microsoft · Vendor-published · documented, not executed here

Extracts medical information from unstructured text with four functions in one API call: named entity recognition, relation extraction, entity linking and assertion detection. It accepts text in English, German, French, Italian, Spanish, Portuguese and Hebrew, can return output in FHIR structure, and runs as a hosted API or an on-premises Docker container. The page says it is provided "AS IS" and "WITH ALL FAULTS" and is not intended or made available for use as a medical device, clinical support or diagnostic tool.

Managed cloud service that needs an account with the vendor; documented, not executed here. The page also describes an on-premises Docker container; it was not tried here.

Source: What is Text analytics for health in Azure Language?, Microsoft Learn. Opened 12 Nov 2026. Also opened: PyPI record of the Azure Text Analytics client library for Python (version 5.4.0, MIT License, Python >=3.8 on the day opened).

Power BI

Microsoft · Vendor-published · documented, not executed here

Microsoft's business analytics platform for connecting, visualising and sharing data, with Power BI Desktop for building reports and the Power BI service for viewing and sharing them. The page calls Power BI a core component of Microsoft Fabric, providing its analytics and visualisation capabilities.

A desktop application plus an online service that needs an account; documented, not executed here.

Source: What is Power BI?, Microsoft Learn. Opened 12 Nov 2026. Also opened: Power BI Desktop sample PBIX files used in the monthly release videos (MIT), PyPI record of powerbiclient, a Jupyter widget for Power BI embedding and reporting in a notebook (version 3.1.1, MIT on the day opened).

Azure Data Factory

Microsoft · Vendor-published · documented, not executed here

A managed cloud service for ETL, ELT and data integration: users create and schedule data-driven workflows called pipelines that ingest data from different stores and transform it with data flows or compute services such as Azure Databricks. A tip on the page says Data Factory in Microsoft Fabric is the next generation of Azure Data Factory and that new users should start there.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: Introduction to Azure Data Factory, Microsoft Learn. Opened 12 Nov 2026.

Azure Open Datasets (catalogue)

Microsoft · Vendor-published · documented, not executed here

Catalogue of curated public datasets on Azure for machine learning projects. On 12 Nov 2026 the page has four sections: Transportation, Labor and economics, Population and safety, and Supplemental and common datasets. No health or genomics section appears in the catalogue on that date.

A catalogue only; documented, not executed here.

Source: Datasets in Azure Open Datasets, Microsoft Learn. Opened 12 Nov 2026.

Azure Open Datasets: 1000 Genomes (deprecation notice)

Microsoft · Vendor-published · documented, not executed here

Azure Open Datasets page for the 1000 Genomes Project (2,504 individuals from 26 populations, 84 million identified variants), stored in the West US 2 and West Central US regions. An "Important Update May 2025" notice on the page says access to the Genomics open datasets on Azure will be deprecated in the coming months.

Access is being deprecated per the page; nothing was downloaded, so this is documented, not executed here.

Source: 1000 Genomes - Azure Open Datasets, Microsoft Learn. Opened 12 Nov 2026. Also opened: CromwellOnAzure, the Microsoft Genomics implementation of the Cromwell workflow engine on Azure. GitHub shows it archived by the owner on 28 July 2025; its notice gives an effective date of 4 August 2025, genomicsnotebook, Jupyter notebooks on Azure for genomics data analysis. GitHub shows it archived by the owner on 9 May 2025; its notice gives an effective date of 12 May 2025.
