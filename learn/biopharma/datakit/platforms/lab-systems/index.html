Lab systems: notebooks, LIMS and instrument data formats

Systems that capture work at the bench before it reaches the analytics platforms: open-source electronic lab notebooks and a LIMS (all server deployments), the LabKey Server modules, a Python library that turns instrument output into Allotrope Simple Model JSON, the Benchling client SDK, and the AnIML schema. Each entry is described from the page opened on 12 Nov 2026.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

eLabFTW

eLabFTW project · Publisher-published · documented, not executed here

Electronic lab notebook manager for research teams, used through the browser, for storing and organising experiments. It also has a database for resources such as antibodies, plasmids, cell lines, reagents and equipment, and features trusted timestamping. Several teams can share one installation, for example at institute level.

AGPL-3.0 per the repository. It is a server deployment, so this entry is documented, not executed here.

Source: GitHub - elabftw/elabftw: :notebook: eLabFTW is the most popular open source electronic lab notebook for research labs., eLabFTW project (elabftw/elabftw GitHub repository). Opened 12 Nov 2026.

SENAITE (senaite.core)

SENAITE project · Publisher-published · documented, not executed here

Open-source laboratory information management system (LIMS) core for enterprise environments, built on the Plone CMS. SENAITE.CORE provides the core functions and entities used by SENAITE.LIMS and the README says it should not be installed without the SENAITE.LIMS user interface.

GPL-2.0 per the repository. It is a server deployment, so this entry is documented, not executed here.

Source: GitHub - senaite/senaite.core: Enterprise Open Source Laboratory System (LIMS), SENAITE project (senaite/senaite.core GitHub repository). Opened 12 Nov 2026.

LabKey Server platform modules

LabKey · Vendor-published · documented, not executed here

Repository of a set of modules that provide core functionality for LabKey Server.

Apache-2.0 per the repository. The repository page carried no further description when opened, and www.labkey.org could not be opened, so nothing beyond the one-line description is stated. It is a server deployment, so this entry is documented, not executed here.

Source: GitHub - LabKey/platform: A set of modules that provide core functionality for LabKey Server, LabKey (LabKey/platform GitHub repository). Opened 12 Nov 2026.

SciNote (open-source ELN)

SciNote · Vendor-published · documented, not executed here

Open-source electronic lab notebook (ELN) for managing laboratory work and keeping experimental data in one place, designed for life science students, researchers, lab technicians and group leaders.

The README states SciNote is developed and maintained by BioSistemika USA, LLC under the Mozilla Public License Version 2.0. It is a server deployment, so this entry is documented, not executed here.

Source: GitHub - scinote-eln/scinote-web: Open source electronic lab notebook (ELN) that helps you manage your laboratory work and stores all your experimental data in one place., BioSistemika (scinote-eln/scinote-web GitHub repository). Opened 12 Nov 2026.

Chemotion ELN

Chemotion (ComPlat) · Publisher-published · documented, not executed here

Electronic lab notebook for chemists. The README records funding from the Deutsche Forschungsgemeinschaft under NFDI4Chem and from the Helmholtz Association, and copyright held by Nicole Jung of the Karlsruhe Institute of Technology.

AGPL-3.0 per the repository. It is a server deployment, so this entry is documented, not executed here.

Source: GitHub - ComPlat/chemotion_ELN: Electronic Lab Notebook, Chemotion (ComPlat/chemotion_ELN GitHub repository). Opened 12 Nov 2026.

allotropy

Benchling (open source) · Vendor-published · open to run here

Python library by Benchling that reads text- or Excel-based output from instrument software and returns JSON conforming to the Allotrope Simple Model (ASM). The README says some schemas do not yet match the published ASM schema (differences are noted alongside each schema), that it does not convert proprietary binary formats, and that no affiliation with the Allotrope Foundation is claimed or implied.

MIT per the repository and PyPI (allotropy 0.1.152, Development Status 4 - Beta, Python >=3.10 on the day opened). Not installed or run here.

Source: GitHub - Benchling-Open-Source/allotropy: A Python library for converting instrument data into Allotrope Simple Model (ASM), Benchling (Benchling-Open-Source/allotropy GitHub repository). Opened 12 Nov 2026. Also opened: PyPI metadata: "Converts to ASM (Allotrope Simple Model) from various file formats".

Benchling SDK (Python)

Benchling · Vendor-published · documented, not executed here

Python SDK for interacting with the Benchling platform.

The SDK shows an Apache-2.0 licence on PyPI (benchling-sdk 1.25.0, Python >=3.9,<4.0), but it is a client for the proprietary Benchling platform and needs an account there, so this entry is documented, not executed here.

Source: PyPI JSON metadata for benchling-sdk 1.25.0, Benchling (PyPI package metadata). Opened 12 Nov 2026.

AnIML XML schemas

AnIML project (ASTM standard) · Publisher-published · documented, not executed here

Official XML schema definitions (core and technique schemas) for the Analytical Information Markup Language, which the repository describes as an ASTM standard XML format for analytical chemistry data and metadata, vendor-neutral and open, with audit-trail support. The repository gives the current schema version as 0.90 (Draft).

Schema files, not software, and no licence is shown on the repository page (it states AnIML is maintained under the ASTM standardisation process), so documented, not executed here.

Source: GitHub - AnIML/schemas: AnIML XML schemas, AnIML project (AnIML/schemas GitHub repository). Opened 12 Nov 2026.
