Platform reference · AWS

Amazon Web Services

Amazon Web Services sells storage, query, workflow and health-data services, and hosts many public life-science datasets through its Registry of Open Data. This page covers S3, Athena, Glue, Batch and Quick Sight, the health services HealthOmics, HealthLake and Comprehend Medical with their scope statements, four public genomics and target datasets on the registry, two public NIH resources served from AWS, and AWS sample code that uses them.

Each entry is written from the page named as its source, opened on the date shown. A vendor's statement about its own product is tagged vendor-published; open-source projects, standards bodies and public agencies are tagged publisher-published. Nothing proprietary was run: an entry that is not executable here says "documented, not executed here".

Amazon S3

Amazon Web Services · Vendor-published · documented, not executed here

Object storage: data is stored and protected as objects, with management features to organise data and configure access. The page lists data lakes, backup and archive and big data analytics among its use cases.

Managed cloud service that needs an account with the vendor; documented, not executed here. Some public datasets in the Registry of Open Data are readable from S3 without an account, as each dataset page states.

Life-science example: The Registry of Open Data on AWS lists datasets, including life-science ones, that are reachable through AWS resources such as S3 buckets.

Source: What is Amazon S3?, AWS documentation. Opened 12 Nov 2026.

AWS HealthOmics

Amazon Web Services · Vendor-published · documented, not executed here

A HIPAA-eligible managed service for bioinformatics. It has three main components: workflows (runs pipelines written in WDL, Nextflow or CWL on provisioned infrastructure), storage (stores and shares genomics data) and analytics (prepares genomics data for multiomics and multimodal analyses). Its important notice says it is intended only for transferring, storing, formatting or displaying data and for workflow infrastructure, and is not a substitute for professional medical advice, diagnosis or treatment.

Managed cloud service that needs an account with the vendor; documented, not executed here. Open-source workflow engines that read the same WDL, Nextflow or CWL files run elsewhere; not tried here.

Life-science example: AWS sample repository (Apache-2.0) with code and example workflows that store, process and query genomic and biological data with HealthOmics.

Source: What is AWS HealthOmics?, AWS documentation. Opened 12 Nov 2026. Also opened: AWS sample (MIT-0) with the code for an automated end-to-end genomics processing and analysis pipeline using Amazon Omics, as its README names the service, and AWS Step Functions.

AWS HealthLake

Amazon Web Services · Vendor-published · documented, not executed here

A HIPAA eligible service for storing, analysing and sharing health data in the FHIR R4 specification. Data is held as native FHIR R4 resources in a data store and reached through FHIR R4 APIs or with SQL through Amazon Athena. Listed uses include interoperability, converting C-CDA and CSV data into FHIR R4, and NLP on unstructured health data. The page says it is not a substitute for professional medical advice, diagnosis or treatment.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Life-science example: AWS guidance (MIT-0) that uses AWS Entity Resolution to match patient resources stored in a HealthLake data store.

Source: What is AWS HealthLake?, AWS documentation. Opened 12 Nov 2026.

Amazon Athena

Amazon Web Services · Vendor-published · documented, not executed here

An interactive query service that runs standard SQL directly on data in Amazon S3, and can also run Apache Spark applications without managing resources.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Life-science example: NCBI documents searching Sequence Read Archive metadata with SQL in Athena on AWS or BigQuery on Google Cloud.

Source: What is Amazon Athena?, AWS documentation. Opened 12 Nov 2026.

AWS Glue

Amazon Web Services · Vendor-published · documented, not executed here

A serverless data integration service to discover, prepare, move and integrate data from many sources. It keeps a central data catalog, lets users build and run ETL pipelines into data lakes, and its catalogued data can be queried from Amazon Athena, Amazon EMR and Amazon Redshift Spectrum.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: What is AWS Glue?, AWS documentation. Opened 12 Nov 2026.

AWS Batch

Amazon Web Services · Vendor-published · documented, not executed here

A fully managed service for batch computing on the AWS Cloud: it provisions compute resources in response to submitted jobs and distributes the workload, so no batch computing software has to be installed or managed.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: What is AWS Batch?, AWS documentation. Opened 12 Nov 2026.

Amazon Comprehend Medical

Amazon Web Services · Vendor-published · documented, not executed here

Uses NLP models to detect entities in unstructured clinical text such as physician notes, discharge summaries, test results and case notes: medical conditions, medications and Protected Health Information. Detected entities can be linked to RxNorm and ICD-10-CM. The page calls it a HIPAA Eligible Service, says it only detects entities in English (US-EN) text, and says it is not a substitute for professional medical advice, diagnosis or treatment.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Life-science example: AWS sample (MIT-0) that combines Amazon Transcribe Medical and Amazon Comprehend Medical to transcribe medical audio and tag the medical entities in it.

Source: What is Amazon Comprehend Medical?, AWS documentation. Opened 12 Nov 2026.

AWS Quick Sight (part of AWS Quick)

Amazon Web Services · Vendor-published · documented, not executed here

Interactive data visualisation and business intelligence: connect to data sources, build dashboards and embed analytics in applications. On the opened page Quick Sight is one feature of a wider AI-powered service named AWS Quick.

Managed cloud service that needs an account with the vendor; documented, not executed here.

Source: What is AWS Quick?, AWS documentation. Opened 12 Nov 2026.

Registry of Open Data on AWS

Amazon Web Services · Vendor-published · documented, not executed here

A registry for discovering and sharing datasets available through AWS resources, with tutorials and usage examples per dataset. The page says that, unless a dataset page states otherwise, the datasets are not provided and maintained by AWS but by third parties under a variety of licences, which users must check.

A catalogue; whether a bucket reads without an account is stated on each dataset page, so this is documented, not executed here.

Source: Registry of Open Data on AWS, Amazon Web Services. Opened 12 Nov 2026. Also opened: Registry source repository (Apache-2.0); it says listed datasets are owned and maintained by government organisations, researchers, businesses and individuals, not provided by AWS.

The Cancer Genome Atlas on AWS

Amazon Web Services · Vendor-published · documented, not executed here

Registry page for The Cancer Genome Atlas, an NCI and NHGRI collaboration covering matched tumour and normal tissue from 11,000 patients across 33 cancer types and subtypes. It lists an open S3 bucket (tcga-2-open, us-east-1) with clinical, biospecimen, expression, copy-number and masked somatic mutation data from the Genomic Data Commons, and a controlled-access bucket (tcga-2-controlled) for aligned reads and annotated, raw and aggregated somatic mutation data. The licence field points to the NIH Genomic Data Sharing Policy.

The open bucket is listed with no AWS account required; the controlled bucket needs authorised access. Nothing was downloaded, so this is documented, not executed here.

Source: The Cancer Genome Atlas - Registry of Open Data on AWS, Amazon Web Services. Opened 12 Nov 2026.

1000 Genomes on AWS

Amazon Web Services · Vendor-published · documented, not executed here

Registry page for the 1000 Genomes Project, a catalogue of human genetic variation whose final phase sequenced more than 2500 individuals from 26 populations. Data sits in the 1000genomes S3 bucket (us-east-1). The licence field says the data is available without embargo and should be cited in the usual way; the page lists the update frequency as not updated.

The page shows AWS CLI access with no AWS account required (--no-sign-request); nothing was downloaded, so this is documented, not executed here.

Source: 1000 Genomes - Registry of Open Data on AWS, Amazon Web Services. Opened 12 Nov 2026.

gnomAD on AWS

Amazon Web Services · Vendor-published · documented, not executed here

Registry page for the Genome Aggregation Database, summary data aggregated from large human exome and genome sequencing projects and released without restriction on use. The v4.1 data set (GRCh38) spans 730,947 exomes and 76,215 genomes. Data sits in the gnomad-public-us-east-1 S3 bucket. The licence field says MIT, with terms of use.

The page shows AWS CLI access with no AWS account required (--no-sign-request); nothing was downloaded, so this is documented, not executed here.

Source: Genome Aggregation Database (gnomAD) - Registry of Open Data on AWS, Amazon Web Services. Opened 12 Nov 2026.

Open Targets on AWS

Amazon Web Services · Vendor-published · documented, not executed here

Registry page for the Open Targets Platform, a data integration resource for identifying and prioritising potential therapeutic drug targets. Releases sit in the open-targets-public-data-releases S3 bucket (eu-west-1), with a notification topic for new releases; the page says data is released every three months. The licence field links to CC0 1.0.

The page shows AWS CLI access with no AWS account required (--no-sign-request); nothing was downloaded, so this is documented, not executed here.

Source: Open Targets - Registry of Open Data on AWS, Amazon Web Services. Opened 12 Nov 2026.

Guidance: multimodal data analysis with AWS health and machine learning services

Amazon Web Services · Vendor-published · documented, not executed here

Code for an end-to-end framework that stores, integrates and analyses genomic, clinical and medical imaging data with AWS HealthOmics, HealthLake, HealthImaging, SageMaker, Athena, QuickSight and S3. The worked example uses the Synthea Coherent Data Set, which the README describes as an open-source, synthetic dataset with FHIR resources, MRI DICOM images, genomic data, ECGs and simple clinical notes linked together by FHIR.

MIT-0 code that deploys into an AWS account; documented, not executed here.

Source: aws-solutions-library-samples/guidance-for-multi-modal-data-analysis-with-aws-health-and-ml-services, GitHub repository aws-solutions-library-samples/guidance-for-multi-modal-data-analysis-with-aws-health-and-ml-services. Opened 12 Nov 2026.

AWS SDK for pandas (awswrangler)

Amazon Web Services · Vendor-published · documented, not executed here

A Python library, described as "Pandas on AWS", that connects pandas to Athena, Glue, Redshift, QuickSight, DynamoDB, EMR and other services and to S3 files in Parquet, CSV, JSON and Excel. The page calls it an AWS Professional Services open source initiative.

The library (version 3.18.0, licence expression Apache-2.0, Python >=3.10,<4.0 on the day opened) installs from PyPI but its calls go to AWS services; documented, not executed here.

Source: awswrangler (PyPI JSON record), Python Package Index. Opened 12 Nov 2026.

Sequence Read Archive in the cloud

National Center for Biotechnology Information · Publisher-published · documented, not executed here

NCBI page saying that SRA data is available on Google Cloud and AWS: all publicly available unassembled read data and authorised-access human data can be accessed and computed on there, which needs a cloud instance to be set up. SRA metadata can be searched with SQL using Athena on AWS or BigQuery on Google Cloud.

Access runs through a cloud account and instance; documented, not executed here.

Source: SRA in the Cloud, National Center for Biotechnology Information. Opened 12 Nov 2026.

PMC Article Datasets on AWS

National Library of Medicine (PMC) · Publisher-published · open to run here

PMC article datasets are freely accessible on AWS through an HTTPS or S3 URL with no log-in, from the world-readable pmc-oa-opendata bucket in us-east-1; adding --no-sign-request to an AWS CLI command reads it anonymously. NLM provides this with the AWS Open Data Sponsorship Program. The page says all legacy PMC Article Dataset files on the FTP and Cloud Services were removed the week of 24 August 2026.

Plain HTTPS or anonymous S3 download per the page; the bucket itself was not requested, so this is documented, not executed here.

Source: Accessing PMC Article Datasets Using Amazon Web Services, National Library of Medicine. Opened 12 Nov 2026.
