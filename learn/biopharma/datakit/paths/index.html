Learning paths

One path per role, joined to the role's modules: after each module, the labs at the same level.

  1. Developers and engineers
  2. Sales, BD and account leads
  3. Delivery leads, PMs and BAs
  4. Leadership and partners
  5. Data and AI engineers
How these paths are built
  • One path per role in sector.yaml. Each path follows the role's modules in ladder order (beginner, intermediate, advanced, expert).
  • A module level takes the labs of the same level. No lab is above intermediate yet, so the advanced and expert levels say so.
  • Developers and data and AI engineers run every lab at the level. Sales and BD, delivery and leadership read one lab per stage at the level, the first in path order.
  • Order within a level: the stage order of the kit's stage registry, then the lab's own time, then its id.
  • 'Do first' lists, for a lab above beginner level, the beginner labs earlier in the same path that share at least one data type with it.
  • A check rebuilds every list from these rules and reports any difference. Times are each lab's own estimate, summed by the site; they are not measured.
