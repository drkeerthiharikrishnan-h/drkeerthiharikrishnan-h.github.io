R Consortium R Submission Pilot 3: SDTM tabulations, ADaM datasets derived in R, and the R programs, as a demo eCTD package

A public test submission in which the ADaM datasets themselves, as well as the tables and figures, are produced by R programs from SDTM tabulations.

Dataset card Regulatory, Clinical · R Consortium R Submissions Working Group (GitHub organisation RConsortium)

The README says the pilot's objective is to test the concept that an R-language based submission package can meet the needs and the expectations of the FDA reviewers, including assessing code review and analyses reproducibility, and that all submission materials and communications from the pilot are publicly available as a working example for future R-language based FDA submissions. Module 1 holds a draft cover letter and a report of tables and figures (report-tlf-pilot3.pdf). Module 5 holds SDTM tabulations in SAS transport (XPT) format with define.xml, define.pdf and a blank annotated case report form (26 files in the folder), and ADaM datasets with define.xml, an ADRG and a specification workbook (9 files). The README lists R programs for five ADaM datasets (adadas, adae, adlbc, adsl, adtte), four output programs and an renv.lock file. In the README the ADRG link and the initial-submission version are marked TBC. None of the data files was downloaded or opened for this card; the folder listings and the README were.
