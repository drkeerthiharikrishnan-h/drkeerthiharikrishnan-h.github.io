Moisture stability example for shelf-life estimation (R package expirest, dataset exp3)

Moisture results for three batches of a drug product over 24 months, shipped as an example dataset in an R package that estimates shelf life.

Dataset card CMC · Pius Dahinden (author and maintainer); Tillotts Pharma AG (copyright holder and funder), as listed on CRAN

The file data/exp3.RData in the package repository is 508 bytes. The package documentation describes it as moisture stability data, in percent weight by weight, for three batches of a drug product over 24 months. It lists 33 measurements with three columns, Batch (b1, b2, b3), Month and Moisture. It says the values correspond to Table XIII of LeBlond, Griffith and Aubuchon, J Valid Technol 2011, 17(3), pages 47 to 68. The package README works through this dataset as its Example 1 and prints a worst-case intercept of 2.456782 and estimated shelf lives of 72.50545 and 96.30552 months. The file was downloaded and checksummed for this card; it was not parsed.

Good for
  • Seeing the shape of a stability dataset, with one row per batch, time point and measured value.
  • Following the package's worked example of pooling batches and estimating shelf life, with the open question about where the numbers come from kept in view.

Why this is not a lab: No published result located. The numbers the package prints are a software example, not a published scientific result. The 2011 article the data are attributed to has not been opened. The three hosts that carry it could not be opened on 11 Nov 2026, and they were not tried again for this card. So it is not established whether the 33 values are measurements of a real product or numbers written for a tutorial, nor which product, method or storage condition they describe. The field synthetic is set to false only because the package documentation calls the values measurements; that is the package's wording, not a checked fact.
