Stanford OpenVaccine RNA degradation, public training set (Eterna/Kaggle)

The public training set of the Stanford OpenVaccine Kaggle challenge: single-nucleotide-resolution degradation and reactivity measurements for short RNA constructs, released with the challenge's model code.

Dataset card Discovery · The eternagame project; the repository LICENSE copyright line names the Board of Trustees of the Leland Stanford Junior University.

Kaggle_RYOS_trainset.csv in the eternagame/KaggleOpenVaccine GitHub repository (16,107,094 bytes, as fetched 2026-11-21). The author counted 1,589 data rows; every row has SN_filter = 1 and seq_length = 107, with seq_scored = 68. Columns include the RNA sequence, a predicted structure and predicted loop type, and per-position measurement arrays for reactivity and for degradation under several conditions (deg_Mg_pH10, deg_pH10, deg_Mg_50C, deg_50C) with their error arrays. The repository README describes the file as the training set for the Kaggle Open Vaccine Challenge and links the accompanying manuscript, Wayment-Steele and others (2022), Nat Mach Intell.

Good for
  • Working with per-nucleotide measurement data: an RNA sequence, a predicted structure, and reactivity and degradation arrays per position with their errors.
  • Training a baseline RNA-degradation model on the public constructs, knowing the published 41% figure is scored on held-out data not in this file.

Why this is not a lab: Published result cannot be rebuilt from the open files. The published figures cannot be checked from this one file. The paper's abstract (Europe PMC, open access) describes single-nucleotide-resolution measurements on 6,043 diverse 102-130-nucleotide RNA constructs and reports that 41% of the winning model's nucleotide-level predictions were within experimental error. The public training file the author downloaded holds 1,589 constructs (all with SN_filter = 1). The training file alone does not hold the held-out constructs the 41% figure is scored against. The README says the same folder also holds test sets; they were not opened for this card, so it is not established whether the figure can be rebuilt from them. No opened page states how the training file relates to the abstract's 6,043 constructs. No lab was built. A learner can still train a baseline degradation model on the 1,589 public constructs.
