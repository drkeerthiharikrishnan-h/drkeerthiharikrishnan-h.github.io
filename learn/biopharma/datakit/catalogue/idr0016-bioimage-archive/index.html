Compound Cell Painting screen in U2OS cells in the Image Data Resource (IDR idr0016, screenA)

The Image Data Resource copy of a Broad Institute Cell Painting screen of about 30,000 compounds in U2OS cells, browsable plate by plate with a per-well annotation table.

Dataset card Discovery · Broad Institute (Wawer and others), published in the Image Data Resource (IDR Project)

IDR screen 1251, idr0016-wawer-bioactivecompoundprofiling/screenA, is described as a reference dataset of profiles for U2OS osteosarcoma cells treated with about 30,000 compounds using the Cell Painting assay. The screen description gives 413 microtiter plates of 384 wells, 6 fields of view per well (a very small fraction of wells have a few sites missing), and five channels per field, each stored as a separate grayscale 16-bit TIFF. Its version history says 20 plates from BBBC022 were moved to idr0036 in August 2017 and 58 plates from the Cell Image Library were added. The study annotation names two publications (Wawer and others, DOI 10.1073/pnas.1410933111; Bray and others, DOI 10.1093/gigascience/giw014), a release date of 2016-12-16 and links to the Cell Image Library, GigaDB and BBBC036 and BBBC047. The annotation CSV downloaded for this card has 158,592 rows (one per well) across 413 plates and 24 columns, among them compound identifier, name, SMILES, PubChem InChIKey, dose and control type. The Cell Painting Gallery lists idr0016 as an alias of its dataset cpg0012, which has its own card.

Where
IDR idr0016, screen 1251 (idr0016-wawer-bioactivecompoundprofiling/screenA)
Access
Open, no login
Size and format
413 plates of 384 wells, 6 fields and 5 channels per field (16-bit TIFF); the IDR pages opened give no byte total, and the Cell Painting Gallery README gives 3.1 TB of images for its alias cpg0012. The annotation CSV is 95,697,614 bytes.. 16-bit grayscale TIFF images (via OMERO / IDR), CSV annotation table, JSON (IDR API).
Licence
CC0 1.0 (study annotation in IDR; copyright Wawer et al). As this site's practice, not as a condition stated in the record, cite the two publications named in the study annotation (Wawer and others 2014; Bray and others 2017) and the IDR.
Data dictionary
idr0016-screenA-annotation.csv
Good for
  • Seeing how a high-content screen is published as plates, wells and fields with a per-well annotation table that links images to compounds.
  • Comparing the same screen in two archives (IDR idr0016 and Cell Painting Gallery cpg0012) and how each describes it.

Why this is not a lab: Too large for a lab. The images run to about 4.76 million TIFF files by this arithmetic (413 plates x 384 wells x 6 fields x 5 channels), far too much for a laptop lab, and the annotation table alone supports only counting plates and compounds. No published analytical result tied to a file small enough to download was opened for this card.
