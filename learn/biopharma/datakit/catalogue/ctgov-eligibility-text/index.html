ClinicalTrials.gov eligibility module (free-text criteria beside structured age, sex and healthy-volunteer fields)

Each study record on ClinicalTrials.gov carries its inclusion and exclusion criteria as free text, next to a few structured fields (minimum age, maximum age, sex, healthy volunteers). The API returns both in one JSON document.

Dataset card Clinical · U.S. National Library of Medicine (National Institutes of Health), ClinicalTrials.gov

The ClinicalTrials.gov API (version 2.0.5 on the day of reading) returns one JSON document per study. Its protocolSection has an eligibilityModule. The API's own field list gives ten fields for that module: eligibilityCriteria, healthyVolunteers, sex, genderBased, genderDescription, minimumAge, maximumAge, stdAges, studyPopulation and samplingMethod. It describes eligibilityCriteria as marked-up text of at most 20,000 characters, healthyVolunteers as a yes or no value, and stdAges (the age group) as calculated from the minimum and maximum age. In the record read for this card, NCT04280705, the criteria text is 2,008 characters long and starts with "Inclusion Criteria:"; the structured fields read minimumAge "18 Years", maximumAge "99 Years", sex "ALL", healthyVolunteers false, and stdAges ADULT and OLDER_ADULT. The API page says the data is refreshed daily, Monday to Friday, and that the version address gives a dataTimestamp; it read 2026-11-20T10:00:05 on 22 Nov 2026.

Where
ClinicalTrials.gov API v2, one study per request: https://clinicaltrials.gov/api/v2/studies/<NCT number>; fields under protocolSection.eligibilityModule. Example read for this card: NCT04280705.

Open, no login

Good for
  • Practising text-to-structure extraction with an answer key in the same document: the structured fields say what the free text should yield for age limits, sex and healthy volunteers.
  • Seeing what the structured fields leave out. Most inclusion and exclusion criteria exist only as free text.

Why this is not a lab: No published result located. A learner can pull age, sex and healthy-volunteer status out of the free text and compare them with the structured fields of the same record. That is a check of a record against itself; no published figure for a dated set of records was located. The clinical scout found none on 10 Nov 2026, and this card's author did not search further. The terms page says the database is updated daily, so a count taken today could not be checked against anything in print.
