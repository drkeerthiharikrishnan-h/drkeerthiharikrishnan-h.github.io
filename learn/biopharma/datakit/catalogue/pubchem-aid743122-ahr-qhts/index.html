Tox21 AhR agonist screen, summary record (PubChem BioAssay AID 743122)

The PubChem summary record of a Tox21 quantitative high-throughput screen for small molecules that activate the aryl hydrocarbon receptor (AhR) signalling pathway, with one activity call per tested substance.

Dataset card Preclinical, Discovery · U.S. Tox21 Program (NCATS, NIEHS/NTP, EPA, FDA), deposited in PubChem BioAssay (NCBI)

AID 743122 is a summary record deposited by the U.S. Tox21 Program (source id AHR641, version 2, last data change 2014-08-21). Its description names a cell-based HepG2-AhR-luc assay, with a cell viability counter screen run in the same wells. The record says it summarises compound activities by combining the AhR agonist mode assay (AID 743085) and the cell viability counter screen (AID 743086), and refers to those two AIDs for the protocols. Its comment explains the activity score: 0 for inactive compounds, 40 to 100 for actives and 5 to 30 for inconclusive compounds. The PubChem summary gives 10,486 substances (8,099 compounds): 1,063 active, 7,945 inactive and 1,478 inconclusive. The full data table downloaded for this card has 16 columns, among them activity summary, AhR potency (uM) and efficacy (%), viability potency and efficacy, and sample source, with four header rows (type, description, unit, active-concentration flag) above 10,486 substance rows; the outcome counts in it equal the summary's. The record carries a disclaimer that artefacts from nonspecific effects such as assay signal interference are possible, and that the activity calls rest on NCATS analysis methods.

Good for
  • Seeing how a screening centre turns a primary screen and a counter screen into one activity call per substance, with a score band for each call.
  • Practising joins between a summary assay record and its primary records (AID 743085 and AID 743086) by PubChem substance id.

Why this is not a lab: Same data as a lab. This record is a summary built from AID 743085, the AhR agonist mode screen whose titration points the lab pubchem-ahr-dose-response-refit refits, plus the AID 743086 viability counter screen. The outcome counts this record publishes are ones a learner would reproduce by counting a column of the same table, so the record adds no analysis to check beyond what the lab already covers.
