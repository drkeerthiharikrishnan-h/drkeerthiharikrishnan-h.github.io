Cell Painting images and profiles of about 30,000 compounds in U2OS cells (Cell Painting Gallery cpg0012)

A Cell Painting screen of about 30,000 compound treatments in U2OS cells, held in the Cell Painting Gallery on the Registry of Open Data on AWS with its images, extracted features and compound metadata.

Dataset card Discovery · Carpenter-Singh and Cimini labs, Broad Institute (Cell Painting Gallery, Registry of Open Data on AWS)

The Cell Painting Gallery is a collection of image datasets made with the Cell Painting assay, in which microscopy images show how labelled cell components respond to genetic, chemical or other treatments; the AWS registry page says it is maintained by the Carpenter-Singh and Cimini labs at the Broad Institute. The Gallery's README lists cpg0012-wawer-bioactivecompoundprofiling as a 30,000 compound dataset in U2OS cells, with original images re-profiled in 2023 and the original profiles kept in workspace/gigascience_profiles. It gives a total size of 10.7 TB (3.1 TB images, 7.6 TB numerical data), Cell Painting protocol v1, and the aliases idr0016, CDRP, BBBC036 and BBBC047, and cites Wawer and others 2014 and Bray and others 2017. The compound metadata table cdrp_compounds.tsv, downloaded for this card, has 30,617 rows and 12 columns (among them broad_sample, cpd_name, pert_type, dos_library, source_name and smiles): 30,616 rows are treatments and 1 is a control.

Where
Cell Painting Gallery cpg0012-wawer-bioactivecompoundprofiling (s3://cellpainting-gallery/cpg0012-wawer-bioactivecompoundprofiling/); aliases idr0016, CDRP, BBBC036, BBBC047
Access
Open, no login
Size and format
10.7 TB in total (3.1 TB images, 7.6 TB numerical data), per the Gallery README; the compound metadata table alone is 5,317,568 bytes. microscopy images, tab-separated metadata (.tsv), extracted feature tables.
Licence
CC0 1.0 Universal (CC0 1.0) Public Domain Dedication. The registry page and the Gallery README ask users to cite the publication for each dataset (here Wawer and others 2014 and Bray and others 2017) and the Gallery paper (Weisbart and others 2024), and to acknowledge the AWS Open Data Sponsorship Program.
Data dictionary
cdrp_compounds.tsv (compound metadata)
Good for
  • Seeing how a large image-based profiling screen is laid out: images, extracted features and compound metadata under one accession, with aliases in other archives.
  • Practising joins between screen metadata and compound identifiers and structures (broad_sample, SMILES).

Why this is not a lab: Too large for a lab. The dataset is 10.7 TB, far beyond a laptop lab, and the small metadata table supports only counting compounds. No published analytical result tied to a file small enough to download was opened for this card.
