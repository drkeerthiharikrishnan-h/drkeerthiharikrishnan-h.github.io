Single-cell RNA sequencing of CD19 CAR T-cell infusion products (CZ CELLxGENE Discover collection be21c2d1)

Single-cell RNA-seq of leftover cells from axicabtagene ciloleucel CAR T-cell infusion products given to 24 patients with large B-cell lymphoma, served by CZ CELLxGENE Discover as one H5AD file.

Dataset card Clinical · CZ CELLxGENE Discover (data contributed by the authors of Deng and others, Nat Med 2020)

The CELLxGENE curation API record for this collection describes remnant cells from axicabtagene ciloleucel infusion products, given as standard-of-care therapy to patients with relapsed or refractory large B-cell lymphoma, loaded on a 10X Chromium with 5' chemistry. The collection holds one dataset. Its record gives 133,405 cells, 19,522 features, assay 10x 5' v1, 24 donor ids, organism Homo sapiens, disease label B-cell non-Hodgkin lymphoma and tissue T cell (primary cell culture). It lists 12 cell-type labels, one of them unknown, and a t-SNE embedding. It gives schema version 7.1.0, first publication 2022-05-20 and revision 2026-06-11, and says raw counts are in raw.X. It marks the cells as not primary data (primary_cell_count 0). One H5AD asset is listed. The record links raw data at the EGA under EGAD00001006325; that link was not opened. The paper's abstract reports single-cell RNA-seq of infusion products from 24 patients. It says complete responders at the 3-month scan had three-fold higher frequencies of CD8 T cells with memory signatures than patients with partial response or progressive disease. The H5AD file was not downloaded for this card.

Data dictionary
CELLxGENE curation API record for the collection
Good for
  • Seeing how a cell-therapy product is characterised at single-cell level, with standard cell-type labels and one id per donor.
  • Reading a curated single-cell record (assay, schema version, cell counts, primary-data flag) before deciding to download a large file.

Why this is not a lab: Too large for a lab. The one data file is 1,687,426,497 bytes by the curation record, which this site judges too large for a laptop lab; it was not downloaded for this card. The abstract's headline result compares patients by clinical response at 3 months. The curation record does not list the file's per-cell columns, so whether each donor's response is inside the file was not checked. If it is not, the response groups cannot be rebuilt from open files. The abstract also gives the result as a three-fold difference with no method named, so the quantity cannot be specified from the abstract alone.
