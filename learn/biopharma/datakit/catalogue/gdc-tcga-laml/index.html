TCGA Acute Myeloid Leukemia project in the NCI Genomic Data Commons (project TCGA-LAML)

The TCGA adult acute myeloid leukaemia cohort as held by the NCI Genomic Data Commons, 200 cases with mutation, copy-number, expression, methylation, clinical and biospecimen files, part open access and part controlled.

Dataset card Discovery · NCI Genomic Data Commons (data from The Cancer Genome Atlas program)

The GDC API record for project TCGA-LAML names it Acute Myeloid Leukemia, disease type Myeloid Leukemias, primary site Hematopoietic and reticuloendothelial systems, released and open. Its summary gives 200 cases and 8,839 files. Case counts differ by data category: 200 for simple nucleotide variation, sequencing reads, copy-number variation, clinical and biospecimen; 194 for transcriptome profiling and DNA methylation; 151 for structural variation. By experimental strategy it lists WGS for 50 cases, WXS for 150, RNA-Seq for 151, miRNA-Seq for 188, genotyping array for 200, methylation array for 194 and expression array for 183. A query on the access field splits the 8,839 files into 4,099 open and 4,740 controlled. One open file was looked up as an example: a masked somatic mutation MAF from WXS, access open, 1,699 bytes, data release 35.0 - 46.0. The GDC status endpoint gave Data Release 46.0 of August 10, 2026. The GDC access page says open data need no login, while controlled data need dbGaP authorization and eRA Commons login. It says open data generally include high level genomic data that is not individually identifiable, most clinical and all biospecimen data, and that controlled data include low level sequencing data and germline variants. The 2013 paper's abstract describes 200 clinically annotated adult cases of de novo AML, 50 by whole-genome and 150 by whole-exome sequencing. The counts agree with the GDC record; this card did not check that they are the same patients. No data file other than the example's metadata record was read.

Access
Open, no login
Size and format
8,839 files with a summed file_size of 43,129,853,942,939 bytes in the project summary, open and controlled together; 4,099 of the files are open access (both as fetched 21 Nov 2026). MAF (gzipped; the example open file), JSON (GDC API records).
Licence
No licence is named. The GDC Data Access Policies page says users of GDC open data must follow the NIH Genomic Data Sharing (GDS) Policy.. The page lists two things a user of open data should do under the GDS Policy. Do not try to identify the research participants. Acknowledge the dataset or accession number and the repository through which the data were accessed. Controlled files need dbGaP authorization and are not used on this site. Linking to the source and storing no copy is this site's practice, not a condition stated by the GDC.
Data dictionary
GDC API project record with summary, GDC API record for one open file (masked somatic mutation MAF)
Good for
  • Seeing how one cancer cohort is split across data categories and sequencing strategies, each with its own case count.
  • Seeing the difference between open and controlled access tiers, file by file, before downloading anything.
  • Practising queries against a public genomics API that returns JSON.

Why this is not a lab: Same data as a lab. The published figures that map onto this project record are the abstract's cohort counts, 200 cases with 50 by whole-genome and 150 by whole-exome sequencing, and the GDC summary gives the same counts. A count alone does not make a lab. The paper's mutation results on the same TCGA AML cohort are tested in the lab tcga-aml-npm1-frequency, which uses the paper's own mutation file as served by cBioPortal (study laml_tcga_pub), not the GDC files.
