Dataset catalogue

Open Reaction Database (ord-data), with one dataset file as the example (Ahneman C-N cross-coupling reactions)

The data repository of the Open Reaction Database, structured organic reaction records stored one dataset per Parquet file, here shown through one file of 4,312 C-N cross-coupling reactions.

Dataset card Discovery · Open Reaction Database (open-reaction-database organisation on GitHub and Hugging Face)

ord-data is a public GitHub repository that describes itself as the official data repository for the Open Reaction Database. Its README says the datasets live under data/ as Parquet files stored with Git LFS, that reads are redirected to a Hugging Face mirror, and that GitHub remains the source of truth. Each file holds one dataset. The reactions are serialized Protobuf messages, one per row, and the dataset name, description and id travel in the file metadata. The README shows how to read a file with the ord_schema package and convert reactions to text (.pbtxt) or JSON. It says the largest file holds 409k reactions in 105 MB. The example file named on this card was downloaded from the Hugging Face mirror and only its Parquet footer was read. It has 4,312 rows in 5 row groups and two columns, reaction_id and reaction (binary). Its metadata give the name Ahneman, the description "C-N cross-coupling reactions from 10.1126/science.aar5169" and the dataset id. The reaction messages were not decoded for this card. The Ahneman abstract describes a palladium-catalysed Buchwald-Hartwig coupling of aryl halides with 4-methylaniline in the presence of potentially inhibitory additives, with computed descriptors as inputs and yield as output. The ORD paper's abstract presents the schema and infrastructure; it names electronic laboratory notebooks among the places reaction data are kept in varied formats.

Size and format
485,772 bytes and 4,312 rows for the example file (as fetched 21 Nov 2026); the README gives 409k reactions in 105 MB for the largest file; the size of the whole repository was not checked. Parquet (one dataset per file; each row a serialized ord-schema Protobuf reaction message).
Licence
Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0) for the datasets under data/; the code is under Apache-2.0. The README says CC-BY-SA-4.0 is the licence that applies to users of ORD data. Under the LICENSE text, anyone who shares the material must give attribution, and shared adaptations must carry the same or a compatible licence. Linking to the source and storing no copy is this site's practice, not a condition of the licence.
Data dictionary
ord-data README, sections Getting the Data and Data Manipulation
Good for
  • Seeing reaction data in one open, structured schema, which the ORD paper contrasts with the varied, often unstructured formats of articles, patents and electronic lab notebooks.
  • Practising reading a Parquet file's footer and metadata before decoding any rows.
  • Seeing how one public repository uses two licences, one for data and one for code.

Why this is not a lab: No published result located. The Ahneman abstract says a random forest gave significantly better predictions of yield than linear regression, but gives no number. Its scores are in the full text, which was not opened; the Europe PMC record marks the article as not open access. The ORD paper's abstract describes the schema and infrastructure and gives no figure for this file. With no published number tied to the file, there is nothing to check a lab against.
