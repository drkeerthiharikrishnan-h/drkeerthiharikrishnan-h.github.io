Tox21 10K Data Challenge, complete training set (NIH/EPA/FDA Tox21, 2014)

The complete training set of the 2014 Tox21 Data Challenge: a multi-record SDF of small-molecule structures labelled active or inactive against twelve nuclear-receptor and stress-response assay endpoints.

Dataset card Discovery, Preclinical · Tox21 Data Challenge 2014, a collaboration of NIH, the US Environmental Protection Agency and the Food and Drug Administration, as stated on the challenge's About page.

The download "tox21_10k_data_allsdf" is a ZIP holding one structure-data file, tox21_10k_data_all.sdf. The author unzipped it and counted 11,764 records separated by the SDF "$$$$" delimiter (unzipped file 24,728,393 bytes, as fetched 2026-11-21). The challenge's data page lists twelve assay endpoints in two panels: a Nuclear Receptor Signaling panel (AR, AhR, AR-LBD, ER, ER-LBD, aromatase, PPAR-gamma) and a Stress Response panel (ARE, ATAD5, HSE, MMP, p53), and says that in the datasets "1" means active and "0" means inactive. The about page describes Tox21 as a federal collaboration of NIH, the Environmental Protection Agency and the Food and Drug Administration, testing a collection it calls "10,000 compounds composed of environmental chemicals and approved drugs". The structure file was parsed only to count records; its per-assay fields were not tabulated for this card.

Licence
No licence or copyright statement for the data was found on the pages opened. The pages are on a US NIH (.gov) resource; the only "Public Domain" wording on the data page heads a section about code tools (LyChI, PCFP), not the datasets.. No explicit licence was located, so teaching use is not confirmed by an opened statement. Link to the source and store no copy (this site's practice); a learner should confirm terms with NCATS before redistributing the file.

Tox21 Data Challenge data and resources page
Good for
  • Reading a real multi-record SDF: parsing small-molecule structures and per-assay activity labels from one file.
  • Practising toxicity classification across twelve assay endpoints, knowing that no published score was located here to check a model against.

Why this is not a lab: No published result located. No page opened for this card states an exact figure that matches the file. The About page calls the library "10,000 compounds"; the complete training SDF the author downloaded holds 11,764 records. The leaderboard page that would carry the winning models' scores was not opened for this card. Without a stated number tied to this file, there is nothing published to check an analysis against, so no lab was built. A learner could still parse the structures and the active/inactive labels and build a toxicity classifier.
