Breast Invasive Carcinoma (TCGA, PanCancer Atlas) in cBioPortal (study brca_tcga_pan_can_atlas_2018)

The TCGA PanCancer Atlas breast cancer cohort as served by cBioPortal, with mutation, copy-number, RNA-seq, protein and clinical data for 1,084 samples and a public web service API.

Dataset card Discovery · cBioPortal for Cancer Genomics (study data from The Cancer Genome Atlas, PanCancer Atlas)

cBioPortal's record for study brca_tcga_pan_can_atlas_2018 names it Breast Invasive Carcinoma (TCGA, PanCancer Atlas), citation 'TCGA, Cell 2018', with twelve PubMed id entries, eleven of them distinct, and links to the original data at the GDC and to the PanCancer Atlas publications. The API record, imported 2026-06-05, gives 1,084 samples in all, 1,066 sequenced, 1,070 with copy-number data, 1,082 with RNA-seq V2 expression, 876 with RPPA, 105 with mass spectrometry and 994 complete samples, on reference genome hg19, with 790 treatment and 852 structural-variant records and links to imaging resources. The cBioPortal FAQ says PanCancer Atlas data can be downloaded study by study through the Datasets page or the DataHub, that mutation calls are used as provided by each publication with no further filtering, and that annotation is standardised with Genome Nexus. The DataHub README says study folders are staging files kept with Git LFS and that zipped copies are offered on the datasets page.

Access
Open, no login
Size and format
1,084 samples (allSampleCount in the study record); the byte size of the study files was not checked for this card. cBioPortal staging files (tab-separated text with meta files), JSON (web service API).
Licence
ODC Open Database License (ODbL) v1.0 for the DataHub; TCGA data under the Broad Institute GDAC TCGA Analysis Pipeline License. Attribute any public use, keep derived datasets open and share adaptations under ODbL (DataHub README). The FAQ asks for citation of cBioPortal and the original data source. The README warns that TCGA data are preliminary, not yet validated, carry significant uncertainty and are likely to change. As this site's practice, not as a condition in the README or FAQ, link to the study and store no copy.
Data dictionary
Study record in the cBioPortal API, meta_study.txt in the DataHub
Good for
  • Seeing how one cancer cohort is spread across data types (mutations, copy number, expression, protein, clinical), with a different sample count for each.
  • Practising queries against a public genomics portal API before touching any file.

Why this is not a lab: No published result located. The figures attached to this study are cBioPortal's own sample counts. The study record lists eleven distinct PubMed ids and none of those papers' results was opened for this card, so there is no published number tied to these files to check. The lab tcga-breast-subtype-mutations uses an earlier TCGA breast study in cBioPortal (brca_tcga_pub) whose paper was opened.
