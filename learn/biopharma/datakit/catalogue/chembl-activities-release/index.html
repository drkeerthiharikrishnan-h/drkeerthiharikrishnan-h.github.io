ChEMBL bioactivity database, release ChEMBL_37 (EMBL-EBI)

A manually curated database of bioactive molecules with drug-like properties, released as whole-database dumps, chemical files and fingerprints, with release notes that count the main entities in the release.

Dataset card Discovery, Preclinical · EMBL European Bioinformatics Institute (EMBL-EBI)

The ChEMBL home page describes ChEMBL as a manually curated database of bioactive molecules with drug-like properties that brings together chemical, bioactivity and genomic data. The release notes for ChEMBL_37, prepared on 01/05/2026, count 2,921,148 compounds, 3,824,604 compound records, 24,527,044 activities, 1,970,438 assays, 18,552 targets and 101,100 documents, and break the assays and activities down by data source, from the scientific literature (1,835,048 assays) to deposited sets such as PubChem BioAssays, DrugMatrix and AstraZeneca DMPK/physicochemical. The FTP directory for the latest release offers the database for MySQL (2.0G), PostgreSQL (1.9G) and SQLite (5.4G), an SDF of compounds (888M), a tab-separated file of chemical representations with SMILES, InChI and InChI Key (279M), FASTA files of targets, fingerprint files, a UniProt mapping and schema documentation, with a checksums file. The schema documentation describes each table and column; in it the ACTIVITIES table holds one row per activity value or end point recorded for an assay in a scientific document.

Where
ChEMBL release chembl_37 (prepared 01/05/2026), FTP directory pub/databases/chembl/ChEMBLdb/latest
Access
Open, no login
Size and format
Per the FTP directory listing of 12 Nov 2026: SQLite dump 5.4G, MySQL dump 2.0G, PostgreSQL dump 1.9G, SDF 888M, chemical representations 279M; release notes 12K. SQLite, MySQL and PostgreSQL dumps (.tar.gz), SDF (.sdf.gz), tab-separated chemical representations (.txt.gz), FASTA, FPS and FPSim2 fingerprint files.
Licence
Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0). The README asks that attribution give the URL of the ChEMBL resource and the release version (chembl_37). REQUIRED.ATTRIBUTION asks for the citation Mendez and others, Nucleic Acids Res 2019 (DOI 10.1093/nar/gky1075), for ChEMBL IDs to be preserved and for the release number to be displayed. Any stored excerpt would have to carry the same licence (share-alike). Link to the release and store no copy.
Data dictionary
chembl_37 schema documentation (plain text), chembl_37 release notes
Standards
InChI
Good for
  • Seeing how a curated bioactivity database is organised: compounds, assays, targets, documents and activities as linked tables, described in a schema file.
  • Learning how a release is versioned and attributed (release number, required citation, checksums) before any data is used.

Why this is not a lab: Too large for a lab. The smallest full database dump is 1.9G and the SQLite one 5.4G, too large for a laptop lab. The figures published with the release are counts in its release notes, so a lab would only count rows, not reproduce an analysis. Smaller deposited sets inside ChEMBL are better lab material.
