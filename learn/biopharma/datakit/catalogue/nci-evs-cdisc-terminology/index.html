CDISC SDTM controlled terminology, published by NCI Enterprise Vocabulary Services

The list of allowed values for coded variables in SDTM datasets, such as sex, units and test codes. NCI Enterprise Vocabulary Services publishes it as one file in several formats.

Dataset card Clinical · NCI Enterprise Vocabulary Services (National Cancer Institute), with CDISC

A folder on the NCI EVS download site. Its ReadMe says the file is a complete list of the controlled terminology used for SDTM and CDASH, and that CDISC and NCI develop and maintain it together. The folder holds the same terminology as text, Excel, HTML, PDF, ODM XML and OWL files, with a file of changes and a date stamp. The date stamp read "Q3 2026, 2026-09-25" on 22 Nov 2026. The text file has eight tab-separated columns: Code, Codelist Code, Codelist Extensible (Yes/No), Codelist Name, CDISC Submission Value, CDISC Synonym(s), CDISC Definition and NCI Preferred Term. The author counted 47,242 data rows: 1,222 rows that define a codelist and 46,020 rows that are terms inside a codelist. One example: the codelist Sex (C66731, submission value SEX) is marked not extensible and has four terms, F, INTERSEX, M and U. Another: the codelist Unit (C71620) is marked extensible and has 950 terms. The ReadMe says the text format leaves out the Notes column of the Excel file.

Where
File "SDTM Terminology.txt" in the folder CDISC/SDTM/ of the NCI EVS download site; the folder's date stamp read Q3 2026, release date 2026-09-25. Earlier versions are in the Archive folder (not opened).

Licence
No licence statement in the two ReadMe files of the CDISC folders. NCI Thesaurus Terms of Use state CC BY 4.0 for NCI Thesaurus; CDISC's own terms were not opened.. The SDTM ReadMe says the terminology is also integrated and distributed as part of NCI Thesaurus, and the NCI Thesaurus Terms of Use release NCI Thesaurus under CC BY 4.0. No opened page says in so many words that this licence covers the CDISC files in this folder, and CDISC's own terms were not opened. This site links to the source and stores no copy (this site's practice).

Standards
SDTM, CDASH
Good for
  • Looking up which values a coded SDTM variable may hold, and whether a company may add its own values (the Extensible column).
  • Checking the coded values in an SDTM dataset against the list, for example the sex and unit columns of a study.
  • Seeing how one terminology is published in a human-readable and several machine-readable formats.

Why this is not a lab: No published result located. This is a reference list that is released again each quarter; there is no published result to reproduce. The clinical scout found none on 10 Nov 2026, and this card's author did not search further. A count of rows taken today could only be compared with the file itself. It is a support dataset for labs that use SDTM data, not a lab by itself.
