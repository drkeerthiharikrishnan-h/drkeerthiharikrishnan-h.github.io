DARTH introductory tutorial on cohort state-transition models in R (Sick-Sicker cost-effectiveness example; a model with hypothetical inputs, not observed data)

R code for a published tutorial that builds a time-independent cohort state-transition model and runs a cost-effectiveness analysis with probabilistic sensitivity analysis.

Dataset card Commercial · DARTH workgroup (Decision Analysis in R for Technologies in Health), GitHub organisation DARTH-gitSynthetic data

This is model code, not a dataset of observations. The article's abstract (Med Decis Making 2023;43(1):3-20) describes a cohort state-transition model as a decision model that simulates the transitions of a hypothetical cohort among health states over time, and says the tutorial implements the time-independent form in R using a previously published decision model, calculates costs and effectiveness outcomes, and conducts a cost-effectiveness analysis of multiple strategies, including a probabilistic sensitivity analysis. The repository README names the main script analysis/cSTM_time_indep.R (Sick-Sicker model, cost-effectiveness, probabilistic sensitivity and value-of-information analysis), two function files in R/, unit and regression tests, and an renv.lock that pins package versions. The README also records a correction in v0.3.0: earlier versions and the published article assigned the Simpson's 1/3 within-cycle correction weights by position instead of by time; with the fix, base-case QALYs are about 0.32 higher per strategy and ICERs change by about 0.4%, conclusions unchanged. It records an erratum too: Table 2 of the article gives the cost of treatment B as $12,000, and the README says the correct value, used in the code, is $13,000. Releases are archived on Zenodo (DOI 10.5281/zenodo.5223092). The code was not run for this card.

Repository README (structure, quick start, correction and erratum)
Good for
  • Seeing how a health-economic model is written as transparent, tested R code: transition matrix, costs, utilities, discounting and within-cycle correction.
  • Running a cost-effectiveness and probabilistic sensitivity analysis end to end, knowing the inputs are hypothetical.

Why this is not a lab: No published result located. The published results are in the article, which Europe PMC marks as not open access; its results were not opened for this card, and the clinical scout could not read them on 10 Nov 2026 either. The README also says that the current code (v0.3.0 and later) no longer gives the article's numbers: base-case QALYs are about 0.32 higher per strategy and ICERs differ by about 0.4%. A lab would therefore have to pin an older release and the article's table, neither of which was opened here. The inputs are hypothetical, so the result would check the code, not a measurement.
