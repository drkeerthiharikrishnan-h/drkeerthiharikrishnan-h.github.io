FLIP AAV capsid viability split (from Bryant and others 2021)

The FLIP benchmark's AAV split: engineered AAV2 capsid sequence variants with a viability score, repackaged from the Bryant and others (2021) deep-diversification study for sequence-to-function model benchmarking.

Dataset card Discovery · The FLIP benchmark project (J-SNACKKB organisation on GitHub); the AAV split repackages data credited to Bryant and others (2021).

full_data.csv.zip under splits/aav/ in the J-SNACKKB/FLIP GitHub repository (13,269,236 bytes zipped, as fetched 2026-11-21). The author unzipped it to full_data.csv (267,513,158 bytes) and counted 284,009 data rows. Each row carries a mutated 28-amino-acid region of the AAV2 capsid (reference UniProt P03135, positions 561-588), the full amino-acid sequence, a continuous score and a binary_score. The split README states the score is the "GAS1_virus_S" score from the original dataset, averaged over all synonymous variants, and that binary_score is a binarisation of the score by a Gaussian mixture model. The author counted binary_score True for 150,992 rows and False for 133,017. The rows span many categories, for example designed, random_doubles, single, stop, wild_type, previous_chip_viable and previous_chip_nonviable, and machine-designed categories, some with "walked" in the name.

FLIP AAV split README
Good for
  • Working with sequence-to-function data: a 28-residue variable region, a full protein sequence, and a measured viability score, with ready-made train/test splits.
  • Training and testing a sequence model on the FLIP AAV splits, knowing that 201,426 rows are in the machine-designed categories the abstract counts and 82,583 are in the other eight.

Why this is not a lab: Licence or access does not allow a lab. The two counts in the paper's abstract can be counted from this file. The abstract (Europe PMC, abstract only) reports 201,426 AAV2 variants designed, yielding 110,689 viable engineered capsids, over a 28-amino-acid segment. The split README describes one group of categories as "designed through machine learning". In full_data.csv those categories hold 201,426 rows, of which 110,689 have binary_score True (counted by code in the review of 22 Nov 2026). The other eight categories hold 82,583 rows. No lab was built for now: the paper is not open access and its full text was not opened, and the README says the raw data came from a repository that carries no licence. A learner can still train and test a sequence-to-viability model on the FLIP AAV splits.
