Dataset catalogue

PHUSE scripts repository, copy of the CDISC pilot ADaM datasets

The ten ADaM analysis datasets of the CDISC pilot study, held in the PHUSE scripts repository with a machine-readable define file.

Dataset card Clinical · PHUSE

The folder data/adam/cdiscpilot01 lists 10 XPT files, a define.xml with its stylesheet, a define PDF, a data guide and a README. On 10 Nov 2026 all 10 XPT files had the same git blob ids as the ADaM files in the CDISC repository, so the bytes are identical.

Where
GitHub phuse-org/phuse-scripts, branch master, folder data/adam/cdiscpilot01
Access
Open, no login
Size and format
97.5 MB for the folder (15 entries). SAS transport (XPT), XML, PDF.
Licence
MIT (the repository licence that the GitHub API reports). The repository licence is MIT. The files are the CDISC pilot data, and the repository does not say whether MIT replaces CDISC's own terms for them. Treat CDISC's terms as applying too and attribute CDISC.
Data dictionary
define.xml for the ADaM datasets
Standards
ADaM, Define-XML
Good for
  • A second place to get the same analysis datasets, in a repository whose licence GitHub reports as MIT.
  • Checking that two public copies of a dataset are the same before you rely on either.

Why this is not a lab: Same data as a lab. These are the analysis datasets the lab "From SDTM to the primary efficacy table" already uses. This folder has no study report of its own, so there is no published result here to reproduce.
