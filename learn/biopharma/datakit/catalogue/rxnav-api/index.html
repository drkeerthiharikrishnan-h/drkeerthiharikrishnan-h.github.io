RxNorm API (RxNav, National Library of Medicine): drug names and codes to RxNorm concept identifiers

A free web service that returns RxNorm concepts, related drugs, classes and National Drug Codes for a drug name or identifier, the usual first step before joining drug records from different sources.

Dataset card Real-world · Lister Hill National Center for Biomedical Communications, National Library of Medicine

The RxNav home page says RxNav and its application programming interfaces support the adoption and distribution of RxNorm, the NLM standard terminology for drugs, and extend it by linking RxNorm drugs to physician-friendly terms (RxTerms) and drug classes (RxClass); RxNav-in-a-Box is a locally installable version. The RxNorm API page calls the API a web service for accessing information from the RxNorm data set, lists functions such as findRxcuiByString (concepts with a specified name), getNDCs, getAllHistoricalNDCs and getApproximateMatch, and gives each function's scope (active, current, or current and historical concepts). A query for the name ticagrelor returned one RxNorm identifier, 1116632, as JSON. The home page also says the RxNav suite will be renamed RxNorm Tools on February 10, 2027, with a new address, and that the tools' functionality will not change. This is a lookup service, not a downloadable dataset; the RxNorm release files themselves were not opened for this card.

Where
RxNorm API, base https://rxnav.nlm.nih.gov/REST/ (example: /rxcui.json?name=ticagrelor)
Access
Open, no login
Size and format
An API service; each lookup returns a small JSON or XML document (the ticagrelor name lookup returned 36 bytes). No bulk size applies to the service.. JSON (API responses).
Licence
RxNav Terms of Service (NLM); the RxNorm API returns non-proprietary RxNorm content, and with one exception no licence is needed. The APIs may be used free of charge, at no more than 20 requests per second per IP address; NLM recommends caching results for 12 to 24 hours. Applications that use NLM data are asked to carry NLM's attribution statement, and may not use the NLM name or logo. RxClass carries SNOMED CT content under the SNOMED CT Affiliate licence provisions of the UMLS licence agreement. The pages opened do not name the one exception for the RxNorm API in their text. This card stores no query results.
Data dictionary
RxNorm API function list
Good for
  • Seeing how a drug name is normalised to one concept identifier, and how that identifier links to National Drug Codes and drug classes.
  • Practising the join step between drug records from different sources (labels, adverse event reports, claims) through a shared identifier.

Why this is not a lab: No published result located. The service answers lookups against a terminology that NLM updates; there is no published result to reproduce. The clinical scout found none on 10 Nov 2026, and this card's author did not search further. It is a support tool for labs that join drug records, not a lab by itself.
