Europe PMC web services: article search, open-access full text and text-mined annotations

Web services of Europe PMC, served from www.ebi.ac.uk. The calls made for this card needed no login or key. One call finds an article record, one returns the full text of an open-access article as XML, and one returns the terms that text mining found in an article.

Dataset card Discovery, Clinical · Europe PMC (the calls are served from www.ebi.ac.uk, the site of EMBL-EBI)

Three calls were made for this card. The search call, asked for PMCID PMC3104487, returned one hit: the record of "The International Stroke Trial database" (Trials, 2011, PMID 21510853), marked open access, with flags that say whether the article has a PDF, supplementary files and text-mined terms. The full-text call for the same article returned a JATS XML document; its licence element states the Creative Commons Attribution License 2.0. The annotations call, asked for disease annotations of PMC11035729, returned 89 annotations for one article; each gives the exact words found, the text before and after, the section, the provider (Europe PMC) and a concept address. A fourth call returned the list of search fields, 143 names. The service's own documentation page was not opened (see the note at the top of this file), so this card describes only what the answers themselves show.

Where
REST base https://www.ebi.ac.uk/europepmc/webservices/rest/ (search?query=..., <PMCID>/fullTextXML, fields) and annotations base https://www.ebi.ac.uk/europepmc/annotations_api/ (annotationsByArticleIds). Examples read for this card: PMC3104487 and PMC11035729.
Access
Open, no login
Size and format
An API service; each call returns one JSON or XML document. No bulk size applies to the service. The number of articles in Europe PMC was not read for this card.. JSON (search and annotations), JATS XML (full text).
Licence
EMBL-EBI Terms of Use (last revised 14th October 2026) for the service; each article carries its own licence. Europe PMC's own copyright page was not opened.. The EMBL-EBI terms say that EMBL-EBI adds no restriction on contributed data beyond those of the data owner unless these terms say otherwise, that it expects attribution in line with good scientific practice, and that some resources have additional specific terms that prevail. Whether Europe PMC has such terms could not be read: its copyright page answered with a bot-check page. Reuse of an article's text depends on that article's own licence; the one read here states CC BY 2.0. This site links to the source and stores no copy (this site's practice).
Data dictionary
Europe PMC REST service, list of search fields
Good for
  • Finding the publications for a trial or a product, and telling from the record which ones have open-access full text.
  • Reading an open-access article as structured XML (sections, tables, licence) instead of a PDF.
  • Seeing what text mining returns for one article: the matched words, their context and a concept address.

Why this is not a lab: No published result located. The service answers lookups against a collection that grows; there is no published result to reproduce. The clinical scout found none on 10 Nov 2026, and this card's author did not search further. The scout also noted that two full-text calls returned no XML on that day, so a lab could not rely on every article being served. It is a support tool for labs that read the literature, not a lab by itself.
