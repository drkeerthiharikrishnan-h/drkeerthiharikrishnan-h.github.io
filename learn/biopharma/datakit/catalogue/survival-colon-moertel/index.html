Adjuvant chemotherapy for colon cancer, time to recurrence and death (R package survival, dataset colon)

Patient-level records from a randomised trial of levamisole and fluorouracil after surgery for colon cancer, shipped as an example dataset in the R package survival.

Dataset card Clinical · Terry M Therneau, author and maintainer of the package, as given in the DESCRIPTION file of the source package

The dataset colon is one object in the file data/cancer.rda of the R source package survival. Its documentation describes it as data from one of the first successful trials of adjuvant chemotherapy for colon cancer, with two records per person, one for recurrence and one for death. It lists 16 columns, among them the treatment arm (observation, levamisole, levamisole plus 5-FU), days until event or censoring, censoring status, event type and the number of lymph nodes with detectable cancer. The documentation names four references and says the data set is closest to that of the trial's final report. It also notes an inconsistency between two of the columns, nodes and node4, which the maintainers chose to leave in. The source package was downloaded and checksummed for this card and the documentation file was read; the data file was not parsed for this card.

Good for
  • Seeing the shape of time-to-event data, with one row per patient and event type, a time and a censoring flag.
  • Practising Kaplan-Meier curves and Cox models on real trial data, knowing that no published number was located to check the result against.

Why this is not a lab: No published result located. Two abstracts of the trial's reports were opened. Neither full text was opened; the hosts refused or could not be reached on 11 Nov 2026. The 1990 abstract gives a median follow-up of 3 years and says that, in Stage C disease, levamisole plus fluorouracil reduced the risk of recurrence by 41 percent and the overall death rate by 33 percent. The 1995 abstract gives a median follow-up of 6.5 years for 929 eligible patients and reductions of 40% and 33%. Both are rounded percentages with no method named, so the quantity cannot be specified without guessing. The package documentation says the data set is "closest to" the final report, not that it is the same data. Its own reference list gives that report's year as 1991 and its title as stage II; the indexed record gives 1995 and stage III. The specification stage found that the one exact number in these sources, 929 patients, matches the file (a provisional reading). A lab that checked only that count would not test the time-to-event analysis, so none was built. The full text of the 1995 report, opened by hand, could reopen this.
