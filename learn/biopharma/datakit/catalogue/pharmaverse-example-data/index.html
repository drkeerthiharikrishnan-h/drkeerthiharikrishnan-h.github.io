SDTM and ADaM test datasets for the pharmaverse R packages (pharmaversesdtm and pharmaverseadam)

Two R packages of test data in CDISC formats: SDTM tabulation datasets, and ADaM analysis datasets built from them by the admiral template scripts.

Dataset card Clinical · The pharmaverse admiral team; copyright holders and funders named in the DESCRIPTION files are Cytel Inc., F. Hoffmann-La Roche AG and GlaxoSmithKline LLC

pharmaversesdtm describes itself as test SDTM data for the pharmaverse family of packages. Its DESCRIPTION file calls it a set of SDTM datasets from the CDISC pilot project used for testing and developing ADaM datasets, and its README adds that some test datasets were sourced from the CDISC pilot project while others were constructed ad hoc by the admiral team, with the source of each given on the package's Reference page (not opened for this card). So not every dataset in it is study data. The README says it holds therapeutic-area-agnostic domains (DM, VS, EG and others) and therapeutic-area-specific ones (RS, TR, OE and others), each in both RDA and CSV formats. pharmaverseadam holds ADaM datasets constructed from the pharmaversesdtm datasets with the template scripts of the admiral family of packages; its README says a script runs the templates of admiral, admiralonco, admiralophtha, admiralvaccine, admiralpeds, admiralmetabolic and admiralneuro and saves the results. CRAN lists pharmaversesdtm 1.5.0 (published 2026-07-01) and pharmaverseadam 1.4.0 (published 2026-10-14). No dataset was downloaded or parsed for this card.

Licence
Apache License 2.0 (LICENSE.md in both repositories; DESCRIPTION files and CRAN pages give Apache License (>= 2.0) and (>= 2)). The licence is stated for each package as a whole. The README says some datasets come from the CDISC pilot project, and no opened page says whether the package licence replaces CDISC terms for those files. Attribute the packages and CDISC, link to CRAN or GitHub, and store no copy. This is a reading for teaching use, not legal advice.

Standards
SDTM, ADaM
Good for
  • Seeing SDTM domains and the ADaM datasets derived from them side by side, in R or as CSV.
  • Following how the admiral template scripts turn tabulation data into analysis datasets, across several therapeutic areas.

Why this is not a lab: No published result located. These are test data for package examples and template development. The README and DESCRIPTION files opened for this card describe that purpose and name no analysis result. The clinical scout found no published result to reproduce on 10 Nov 2026, and this card's author did not search further.
