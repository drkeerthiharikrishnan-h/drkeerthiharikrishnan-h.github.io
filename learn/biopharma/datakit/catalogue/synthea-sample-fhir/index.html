Synthea sample patient records (synthetic, not real patients): FHIR, C-CDA and CSV downloads

SYNTHETIC data: zipped sets of simulated patient health records produced by the Synthea patient generator, in FHIR, C-CDA and CSV formats.

Dataset card Real-world · The Synthea project (GitHub organisation synthetichealth); the Synthea README gives copyright 2017-2025 The MITRE Corporation for the generatorSynthetic data

These records are synthetic. The Synthea README describes Synthea as a Synthetic Patient Population Simulator whose goal is to output synthetic, realistic (but not real), patient data and associated health records in a variety of formats, and the sample-data repository describes itself as sample data generated by Synthea. The README lists the generator's features as a birth-to-death lifecycle, demographics that default to Massachusetts census data, and encounters, conditions, allergies, medications, vaccinations, observations, labs, procedures and care plans, exported as HL7 FHIR (R4, STU3, DSTU2), C-CDA and CSV. The sample-data repository's downloads/latest folder holds five zip files: synthea_sample_data_ccda_latest.zip (4,064,713 bytes), synthea_sample_data_csv_latest.zip (5,446,315 bytes), synthea_sample_data_fhir_dstu2_latest.zip (7,985,092 bytes), synthea_sample_data_fhir_latest.zip (24,052,464 bytes), synthea_sample_data_fhir_stu3_latest.zip (14,749,651 bytes). The file names in that folder do not state the FHIR version of the plain 'fhir' file; the dated files in downloads (September 2019 and November 2021) name R4, STU3 and DSTU2, and there is also a 10k_synthea_covid19_csv.zip. The repository has no README. No zip file was downloaded or opened for this card, so the number of patients is not given.

24,052,464 bytes for synthea_sample_data_fhir_latest.zip; the five files in downloads/latest total 56,298,235 bytes (GitHub contents listing). ZIP of HL7 FHIR resources (JSON), ZIP of C-CDA documents, ZIP of CSV tables.
Licence
No licence statement was found for the sample data (no licence file in the sample-data repository); the Synthea generator is under the Apache License 2.0. The GitHub licence API answered 404 for the sample-data repository on 12 Nov 2026. The Apache License 2.0 stated in the Synthea README covers the generator software; no opened page says whether it also covers the generated sample files. This card links to the repository and stores no copy and no preview.

Good for
  • Seeing what a longitudinal patient record looks like as FHIR resources, C-CDA documents and flat CSV tables, without handling real patient data.
  • Practising parsing and joining health-record exports, knowing the patients are simulated.

Why this is not a lab: No published result located. These are simulated records generated for demonstration; the clinical scout found no published result to reproduce on 10 Nov 2026, and this card's author did not search further. A count taken from synthetic files would test only the generator run that made them. No licence statement was found for the sample files either.
