BAGEL2 core-essential and non-essential reference gene lists (Hart Lab)

The two reference gene lists shipped with the BAGEL2 software: a core-essential set (CEGv2) and a non-essential set (NEGv1), used to calibrate and quality-control CRISPR knockout screens.

Dataset card Discovery · Hart Lab, as named in the repository's LICENSE copyright line.

Two tab-delimited files in the hart-lab/bagel GitHub repository. CEGv2.txt (15,088 bytes) has the header columns GENE, HGNC_ID, ENTREZ_ID and 684 gene rows. NEGv1.txt (21,712 bytes) has the same header and 927 data rows, of which 926 are distinct gene symbols (one symbol appears twice); the author counted these from the files, as fetched 2026-11-21. The README describes BAGEL2 as "a robust gene essentiality identifier from CRISPR-cas9 genome wide pooled library screen data" and names two references (Kim and Hart, Genome Med 2021; Hart and others, Mol Syst Biol 2014). These two files are reference sets, not screen measurements; the repository also ships an example screen (HAP1-TKOv3-EXAMPLE.txt) in its pipeline-script-example folder.

Good for
  • Seeing the reference gene sets that CRISPR screen quality control is calibrated against: a core-essential list and a non-essential list, with HGNC and Entrez identifiers.
  • Using the two lists as positive and negative controls to score essentiality in a separate CRISPR knockout screen.

Why this is not a lab: No published result located. These two files are reference gene lists (a core-essential set and a non-essential set) used to calibrate and quality- control CRISPR screens, not a measured result dataset. No page opened for this card states a published figure that these two files themselves reproduce; the 684 and 927 counts above were taken from the files. The README points to the BAGEL2 method and its two reference papers, but a reference list has no result of its own to check an analysis against. A learner would use these lists as positive and negative controls to score essentiality in a separate CRISPR screen (the repository ships an example screen), rather than reproduce a number from them.
