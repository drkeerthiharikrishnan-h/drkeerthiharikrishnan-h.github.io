R Consortium R Submission Pilot 1: an eCTD-style package of ADaM datasets and R programs sent to FDA

A public test submission, organised as a demo eCTD package, in which the analysis tables and figures are produced by R programs from ADaM datasets.

Dataset card Regulatory, Clinical · R Consortium R Submissions Working Group (GitHub organisation RConsortium)

The README says the pilot's objective is to test the concept that an R-language based submission package can meet the needs and the expectations of the FDA reviewers, including assessing code review and analyses reproducibility, and that all submission materials and communications from the pilot are publicly available as a working example for future R-language based FDA submissions. Module 1 holds the cover letter and a report of tables, listings and figures (report-tlf.pdf). Module 5 holds ADaM datasets in SAS transport (XPT) format with a define.xml file and an Analysis Data Reviewer's Guide (adrg.pdf), and four R programs for the demographic, efficacy, primary and Kaplan-Meier outputs. The README links the FDA statistical review responses and says the analysis can be re-run by following the ADRG. The module 5 dataset folder lists 15 files. None of the files was downloaded or opened for this card; the folder listing and the README were.
