Drug response in bulk RNA-seq, from a public count matrix

Compute how much dexamethasone raises six glucocorticoid-responsive genes in human airway smooth muscle cells, from NCBI's raw count matrix of GEO series GSE52778, and compare with the fold changes printed in the paper.

1. The question

By how much does dexamethasone raise the expression of CRISPLD2, DUSP1, KLF15, PER1, TSC22D3 and FKBP5 in primary human airway smooth muscle cells?

A drug-response experiment on cells is read out as a fold change per gene. The same experiment can be re-quantified by a public archive with a newer genome build and a different pipeline. Comparing the two shows how much of a printed number belongs to the biology and how much to the pipeline.

From: Table 1, column headed Ln[ Fold Change ] (numerically log2 of Mean FPKM Dex / Mean FPKM Control), rows CRISPLD2, DUSP1, KLF15, PER1, TSC22D3, FKBP5[1]

The series matrix file carries each sample's treatment.[2][3][4]

6. What goes wrong in practice

  • The header says Ln but the numbers are log2. Table 1 heads its fold-change column Ln[ Fold Change ]. The values equal the base-2 logarithm of the two mean FPKM columns printed beside it (for C7, log2 of 38.41 over 3.76 is 3.35, as printed; the natural log would be 2.32). Test a printed ratio before you trust a header. [1]
  • Not every sample belongs to the comparison. GEO lists 16 samples, four cell lines under four treatments. The paper compares dexamethasone alone with untreated cells, 4 against 4. Take the groups from the treatment field of the series matrix, never from column positions. [2][1]
  • The archive's counts are not the paper's numbers. The paper quantified hg19 with Cufflinks and tested with Cuffdiff. The count matrices in GEO are NCBI-generated (GRCh38.p13, Annotation Release 109); the download page does not say which input or pipeline NCBI used. A fold change computed from NCBI's counts answers the same question by a different route, so it differs in the decimals. [1][3]
  • Rows are gene ids, not gene names. The count matrix is indexed by NCBI GeneID. Join it to a gene table (here NCBI Gene's human table) to find a gene by its symbol, and check that one symbol gives one id. GEO's own annotation table for these matrices used Annotation Release 109; a current table can carry a newer symbol. [3]
  • The gene count of a differential expression list depends on the pipeline. The paper reports 316 differentially expressed genes after Benjamini-Hochberg correction in Cuffdiff. Another test on other counts gives another number. A list size is not a stable value to reproduce; a fold change of a named gene is closer to one. [1]
  • This lab does not reproduce the printed decimals. Run on 12 Nov 2026, NCBI's counts give the same direction as the paper for all six genes, but the log2 fold changes differ from Table 1 by more than the 0.005 tolerance. Five of the six come out between about 0.08 and 0.15 lower than printed; TSC22D3 comes out 0.006 higher. This site's check records this as not reproduced. The lab keeps the result and does not widen the tolerance. Seen in this lab's data; the notebook shows it.

7. The same job on each platform

  • Open source executed here The lab's notebook downloads the GEO series matrix, NCBI's raw count matrix and the NCBI Gene table, reads them with pandas, computes counts per million and group means with numpy, takes log2 of the dexamethasone over control ratio for six genes, and compares it with Table 1. This site's check runs it in a fresh Python process.[5][6]
  • AWS documented, not executed herepublisher-published NCBI says all publicly available unassembled SRA read data can be accessed and computed on in Google Cloud and AWS, which needs a cloud instance, and that SRA metadata can be searched with SQL in Athena or BigQuery. A learner could search there for the runs of this GEO series. Not done here.[7]
  • Open source documented, not executed herepublisher-published nf-core/rnaseq analyses RNA sequencing data from organisms with a reference genome and annotation. It takes FASTQ or BAM files, runs QC, trimming and (pseudo-)alignment, and produces a gene expression matrix and QC report. A learner could re-quantify this series' reads with it and repeat the notebook's ratios on that matrix. Not run here.[8]
  • Google Cloud documented, not executed herevendor-published BigQuery is a fully managed, serverless data platform for analysing data with SQL and Python without managing infrastructure. A learner could load the count matrix and sample sheet as tables and compute counts per million, group means and their ratio in SQL. Not run here.[9]
