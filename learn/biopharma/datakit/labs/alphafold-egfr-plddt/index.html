How confident is a predicted protein structure

1. The question

How confident is the AlphaFold model of human EGFR, residue by residue? What is the mean pLDDT and what share of the 1,210 residues falls in each of the four confidence bands?

A predicted structure is only as useful as its confident parts. The per-residue score says which regions of a model can be relied on and which cannot, and a single average hides that. Computing the summary yourself shows what the database's headline numbers mean.

From: Record with entryId AF-P00533-F1, fields globalMetricValue and fractionPlddtVeryLow, fractionPlddtLow, fractionPlddtConfident, fractionPlddtVeryHigh[1]

6. What goes wrong in practice

  • The database gives two values for the same mean. The mean over the 1,210 residues is 75.9499. The model's mmCIF file states 75.95. The API reports 75.94. With a tolerance of half a unit in the last digit, the mean in this lab does not reproduce the API value; the four fractions do. The cause is not known. On the three isoform entries, checked by code when the lab was built, the API value differed from the mean of the published scores by +0.03, -0.01 and 0.00. Seen in this lab's data; the notebook shows it.
  • An average over atoms is not an average over residues. Every atom of a residue carries the residue's score, and large residues have more atoms. Averaging the B-factor column over all 9,392 atom lines gives 76.29, not 75.95. Keep one value per residue before you average. Seen in this lab's data; the notebook shows it.
  • A score that sits exactly on a band edge. Two residues (130 and 886) score exactly 90.00. The training page writes the bands with strict inequalities, which leaves 90 in no band. The database's own confidence file puts both in the very high band. Putting them in the lower band changes two fractions by more than the tolerance. [4] Seen in this lab's data; the notebook shows it.
  • The API answer is a list, not one record. The response for P00533 holds four records, one for the canonical sequence and three for isoforms, each with its own mean and fractions. Select the record by its entry id (AF-P00533-F1), not by its position in the list. [1]
  • Low confidence is not the same as a wrong structure. The training page gives two reasons for a low score. The region may be flexible or disordered and have no fixed structure, or the method may lack the information to predict it. Both usually give a pLDDT below 50. Do not read coordinates in those regions as a shape. [4]
  • The version is part of the file name. This lab uses model version 6; the API lists versions 1 to 6 for this entry. A file from another version is a different model with different scores. Record the version with every number you report. [1]

7. The same job on each platform

  • Open source executed here The lab's notebook downloads three files for human EGFR: the AlphaFold model (PDB format), its per-residue confidence file and the model in mmCIF format. It reads one pLDDT score per residue from the model. It uses pandas to compute the mean score and the share of residues in each of the four confidence bands, then checks them against the database's values. This site's check runs it in a fresh Python process.[5]
  • AWS documented, not executed herevendor-published Amazon S3 is an object storage service that stores data as objects within buckets. For this lab a learner would store the EGFR model file, or the per-residue score table taken from it, as objects in a bucket for later steps to read. Not done here.[6]
  • Google Cloud documented, not executed herevendor-published BigQuery is a managed data platform for analysing data with SQL and Python. The page says data can be batch loaded from local files or Cloud Storage, in formats that include CSV. For this lab a learner would load the per-residue pLDDT table and compute the mean and the band shares with an aggregation query. Not done here.[7]
  • Open source documented, not executed herepublisher-published DuckDB is an SQL database that runs inside the calling program, with no separate server, and reads CSV and Parquet files directly. For this lab a learner would save the per-residue scores as a CSV file and compute the mean pLDDT and the share of residues in each band with SQL queries. Not done here.[8]
  • Visualisation tools documented, not executed herevendor-published Streamlit is an open-source Python framework for data apps and dashboards. For this lab a learner would wrap the per-residue table in a small app that plots pLDDT along the chain and shows the four band shares. Not done here.[9]
